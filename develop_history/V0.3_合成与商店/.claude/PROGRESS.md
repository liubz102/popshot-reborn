## ⏳ 待用户验证 —— **M3 spike，这一条不过 M5/M7 全要重新设计**

### ⏳ [M3] 穿上装备之后，属性在游戏里真的变了吗？

**背景**：加成是**客户端自己**查本地 `EquipBonus.ini` 算的，服务端只下发
itemId（FINDINGS §1）。我们现在把身上的装备 id 塞进了 `0x030b`，
但**这条链一次都没在真客户端上跑过**。

**怎么做**（三段，做完一段记一段；每段都要**先进房间**再敲命令 ——
`0x030b` 是房间级的，座位得先被 `0x0300` 标成已占用）：

```bash
start.bat
```

进游戏 → 登录 → **建一个房间**（先别开局），然后在另一个终端里：

**① 血条变长（100% 生效的加法，最好看，先验这个）**

```bash
python tools/gs_ctl.py equip 1010037 && python tools/gs_ctl.py equip 1020062 && python tools/gs_ctl.py equip 1050037 && python tools/gs_ctl.py equip 1040037 && python tools/gs_ctl.py equip 1030058
```

上衣+8 / 下装+6 / 头脸+5 / 鞋+7 / 手套+3 = **HP +29**。
泰尔基础 HP 是 100 ⇒ **进图之后血条最大值应当是 129，长出约三成**。
（用 `python tools/gs_ctl.py inv` 可以随时看现在穿着什么。）

**期望看到**：开一局，血条明显比平时长；`unequip 1010037` 之后再开一局变回去。

**② 移动速度（100% 生效的百分比）**

```bash
python tools/gs_ctl.py unequip 1010037 && python tools/gs_ctl.py equip 1010043
```

上衣 `movespd +6`。泰尔基础速度 7.0 ⇒ 7.42。要是①过了这条可以跳过。

**③ ★ 武器 —— 这一条最不确定：`0x030b` 里放武器 id，客户端会不会真换枪？**

```bash
python tools/gs_ctl.py equip 1120012
```

`리볼버 D2`，**伤害 5**（基础左轮是 4）。开一局打怪看伤害数字。

**期望看到**：伤害从 4 变成 5。**没变也是有效结论** —— 说明武器要走另一条
路（多半是 `0x0604`），M5 的换装设计要跟着改。

**怎么告诉我**：一句话就行 ——「①血条变长了 / 没变」「③伤害变了 / 没变」。
有截图更好（`logs/server.out` 里会有 `← 回 0x030b … 装备 [...]` 那几行）。

**当前状态**：等待中。

**⚠ 止损**：①都不生效 ⇒ 说明「往 `0x030b` 里加装备 id」这条路走不通，
**停下来重新拍板**，不要继续往 M5 写代码。
