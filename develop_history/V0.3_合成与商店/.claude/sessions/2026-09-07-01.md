- 新模块 `server/databackup.py`（`BackupService`：目录快照 + manifest、
  daemon 线程 `Event.wait` 到设定时刻、按 manifest 时刻清理、回滚前留一份、
  写前过今天的校验器、`admin_survives`、`groups_of` 给页面分组）。
- `config.py`：三个键 + `_clean_time` + **写回**（`save_keys` / `ensure_keys` /

- `shopcfg.write_lock()` / `all_write_locks()` / `config_filenames()` /
  `config_title()` / `validator_of()`；`account_store.AccountStore.lock` /
  `check_document`。
- `app.py`：`--no-backup`、启动 `ensure_keys`、起 `BackupService`、
  `web_server.serve(backup=)`；`web/server.py` `make_server(backup=)`；
  `web/admin.py` 五条路由 + 在线 / 战斗判定 + 回滚后 `ensure_item_fields` /
  `realign_levels` / `_push_all_online`（踢掉备份里不存在的账号）。

- 配套：`.gitignore` 加 `/server/data/backups/` 和 `/config/server.config.*.tmp`；
  `build-common.ps1` `$must` 加 `databackup.py`、自检加 `--no-backup`；
  `tools/server-package/server.config` + README 补一节。
- 测试：新 `test_backup.py`（48 项）；`test_web_admin` 加 `AdminBackupApiTests`
