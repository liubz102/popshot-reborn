# 2026-09-09 会话 20 —— 修「穿着火焰蝙蝠扔苹果弹打空 → 客户端闪退」

## 题目

用户在 `main` 实机试玩（testuser1 + 1 个 bot 对战），01:36:42 客户端闪退。
给了 `game_patched/Dump/`（`LastCrashReport.txt` + `BigShotV0311N001.mdmp`）
和 `logs/`，要查原因并修。

## 查明（§47）

- 崩在 `0x47ea6c: mov eax,[edi]`，`EDI = 0`。栈：`0x492a4e`（`OnExplode`）
  ← `0x49194e`（`0x040e` 内层分发）← `0x407dbc` ← `0x405815`（收包 flush）。
- 崩前 45 ms 自己发了一发 `rpExplode`：句柄 100058、**目标 0**、命中类型 0、
  **flags 0x200**、伤害 38（hook 日志 `Encrypt#597`，服务端 01:36:42.058 也收到了）。
  本局 11 发里只有它带 0x200；bot 的 flags 恒 0。自己的包本地回环处理
  （V0.2 §151），所以射手自己先崩。
- `0x200` 是 `0x47e618` 尾巴（`0x47e716..0x47e76b`）置的：射手 `IncSplashRange`
  装备加成 > 0 且 15% 门开 且武器有溅射。**不看有没有目标。**
  全 `EquipBonus-Chn.ini` 只有 `220003` 火焰蝙蝠带 IncSplashRange，用户 01:35 刚穿上。
- `OnExplode` 查不到目标句柄仍会调 `+0x12c = 0x47e776(NULL, flags, pos)` 画提示；
  头射那一支（`0x20`）有判空，「ESPERAN SPLASH!」那一支（`0x200`）的**中国区分支**
  没有 —— `0x47ea21` 取图后 `0x47ea6c` 读目标位置就崩。韩国区分支不碰目标。
- 收方拿 `flags & 0x200` 算溅射范围倍率（`0x492785`），所以这一位不能在服务端抹。

## 做法（D55）

| 文件 | 改了什么 |
|---|---|
| `hook/bshook.c` | 新增 `try_patch_splash_visual_guard()`：`0x47ea21` 头 5 字节改 `E9` 跳 naked detour，`edi == 0` 走函数尾 `0x47eb0e`，否则补回 `push 7 ; lea eax,[ebp+0xc]` 跳回 `0x47ea26`；`patch_thread` 里排在 IME 那组后面；`BSHOOK_KEEP_SPLASH_VISUAL_CRASH=1` 保留原版 |
| `hook/bin/bshook.dll` / `bsloader.exe` | `hook\build.bat` 重编（DLL 175104 → 175616 字节；loader 只差 PE 时间戳 6 字节，编译告警 C4819/C4474 是老的，DLL 里中文串仍是 UTF-8）|
| `re/packet_api.md` §5.3 | `+20` 补一张表：`0x01 / 0x10 / 0x800 / 0x100`（§16）+ **`0x200`**（§47），加「目标 0 + 0x200 会让中国区客户端闪退」的警告 |
| `.claude/FINDINGS.md` §47、`DECISIONS.md` D55、`PROGRESS.md` | 结论 / 取舍 / 待验证 N-53 |

服务端一行没改（bot 从不发 0x200，服务端也不该改这一位）。

## 验证

- 特征串 17 字节和镜像 `0x47ea21` 逐字节相同；`0x47eb0e` 确认是函数尾
  （`mov ecx,[ebp-0xc] ; pop edi/esi/ebx ; mov fs:[0],ecx ; leave ; ret 0xc`），
  从 `0x47ea21` 跳过去和 `0x47e9c2` 那条 `je` 的栈状态一致。
- 实机：`tools/launch.ps1 -DebugLog` 拉起客户端（服务端沿用 01:27 起的那个 debug 实例），
  hook 日志 01:59:12「★溅射加成提示判空 @ 0047EA21」。验完把客户端关了，服务端还在跑。
- **没有在实机上再扔弹复现**（要 computer-use）。见 PROGRESS N-53。

## 遗留
