# 2026-09-09 会话 19 —— 修「一个角色穿铠甲，另两个角色自动脱掉」

## 题目

用户在 `dist/PopShot-portable-win64_V0-3-0 - 副本` 实机：三个默认角色，
一个穿上铠甲，另外两个的铠甲就自动脱了。要查原因、修掉，并查武器 / 技能
有没有同样的问题。

## 查明（§46）

- `logs/server.out` 01:00:41：泰尔穿 `1010052` → 服务端「顶掉 [2020023, 2010047]」
  （卡希尔的）；`3120011`（布洛克武器槽 1）顶掉 `1120042`（泰尔武器槽 1）。
  整局客户端**一发 `0x0703` 都没发**。
- 根因：`shopdata.resolve_equipped()` 整份 `equipped` 用**一个**总掩码收敛，
  同 `part_flag` 就丢，没看角色。客户端是三个掩码、一个角色一个（§31 ①）。
- 客户端判冲突的两处（这次逆出来的）：预检 `0x55832c` 只查角色限定那一个掩码；
  收集要先脱的旧件 `0x415304(Equipment, &out, 角色, PartFlag)`，
  条件 `(旧.角色 == 新.角色 ‖ 旧.角色 == -1) && (旧.PartFlag & 新.PartFlag)`。
- 受影响：凡角色限定的装备 —— 铠甲各部位 / 套装、武器三槽、突击技（32）、
  喷漆（64）、戒指（16384）。称号 / 宠物不限角色且不与它们共用 `part_flag`，没事。
- 顺带核对：物品库 `items.json` 里角色限定和原版不一样的只有三把 GoldenKey
  （`part_flag 0`，不占槽），不影响。

## 做法（D54）

| 文件 | 改了什么 |
|---|---|
| `server/shopdata.py` | 新增 `SLOT_MASK_COUNT` / `slot_owners(item)`；`resolve_equipped` 改成三个掩码各算各的；`conflicts` 加「角色掩码有交集」 |
| `server/shop.py` | `EQUIPPED_SLOT_MASK_COUNT` 改成别名；`equipment_slot_masks` 改走 `slot_owners` |
| `test_shopdata` / `test_account_store` / `test_gameserver` / `test_shop` | 合成表加卡希尔 / 布洛克的上衣和一件「不限角色上衣」；新增跨角色不顶、同角色照顶、不限角色三掩码都占、`0x0604` 掩码 `[1,1,1]` 等用例；`conflicts(1120041, 2120041)` 从 True 翻成 False |
| `re/packet_api.md` | `0x0702/0x0703` 节补「冲突按角色算」 |

存档不迁移：被错顶的装备只是从 `equipped` 掉出来，`inventory` 还在，重穿即可。
