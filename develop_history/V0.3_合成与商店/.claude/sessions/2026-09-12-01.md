# 2026-09-12 会话 01 —— 管理页「装备卖出」

## 做了什么

原版没有卖出功能。客户端那发上行 `0x0603` 的语义早就逆出来了（单 itemId，
「되팔기 转卖」对话框的确定键），但应答 `0x0503` 一直没逆完，本版 PROGRESS
把「游戏内卖出」列在「不做」里。这一版**走管理页**，协议一个字节没动。

新标签页「装备卖出」排在「金币 / 经验」和「玩家仓库」之间，**三档身份都进得来**：
玩家卖自己的，管理员卖他那个同名游戏账号的，找不到同名号就把左右分区盖住。
左边是待卖出购物车（金额实时变 + 「将返还的材料」），右边是自己的仓库
（筛选那三套和「修改仓库」弹窗完全共用）。

## 用户拍板的（问过两轮）

第一轮四条：① 合成装备**退材料实物**（不是折价）；② 查不到价的走「其他物品」
兜底价；③ 什么都能卖，穿着的自动脱下，但**对局中不许卖**；④ 只记服务端日志。
出厂价：珠子 100 / 通用 200 / 特殊低 300 / 特殊高 600 / 卡片 200 / 装备 95%
（`other_price` 用户没给，本工程定 100）。改价权限：系统管理员 + 运营。

第二轮一条（用户当场点的）：**管理员没有同名游戏账号时卖不了，但照样要能改价**
—— 第一版遮罩盖住了整个 `.panel-body`，连工具条一起盖了。改成只盖 `.sell-split`。

## 走过的弯路

1. **CSS 特异性栽了两次**。`.sell-qty-panel { height: auto }` 盖不住
   `.modal .panel { height: min(640px,100%) }` —— 一个类打不过两个类，和写在
   后面没关系（一个数字输入框撑成了 940×640）。`.sell-price-row .field` 同理：
   `.field` 默认 `flex-direction: column`，光写 `display: flex` 不改方向。
2. **一行塞五列，名字只剩一个字**。照「修改仓库」那样用
   `minmax(230px,1fr)` 多列网格，卖出页一格还要塞 余量 / 单价 / 按钮 ⇒
   1440 宽下名字被压成「黑」「红」「铁」。改成**一行一件**。
3. `shopcfg.shop()` / `recipes()` 返回的是 `(内容, 警告列表)` 元组，不是内容本身。
