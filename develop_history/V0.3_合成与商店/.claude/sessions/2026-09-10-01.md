# 2026-09-10 会话 01 —— 修「岩浆巨龙 boss 永久无敌卡关」

## 用户要什么

「最新版本配置到云服务器后，有人试玩说闯关模式熔岩巨龙那关，到 boss 房间后
**有时**boss 会永远无敌然后卡关。正常应该是 boss 先无敌一会儿，然后有剧情
boss 变成可以打的状态。日志在 `bug调查/16`，日本时间今天 9:15 前后，
服务器是中国时区，玩家昵称 `Jungle音`。请帮我调查并修复。」

## 怎么定位到那一局

`Jungle音` = 账号 `d314010739`（`online.log` 建房那几行）。日本 9:15 = 中国 8:15。
`server.out` 里那段时间只有一局岩浆巨龙：

```
08:09:55  房间 #30 开局（args=(2,1) = 关卡 2 / 简单，单人房）
08:11:56  换图 -> Quest02_2（boss 图）
08:14:02 / 08:14:47 / 08:15:03  玩家三条命用完（凶手=255）
08:15:09  gcpEndQuest -> 结算「未完成」，分数 594
```

**决定性证据**：`08:11:57` 进图到 `08:15:09` 放弃，这 3 分 12 秒里
**一发 `0x0410` 都没有**。`0x0410` 只在打到怪时发、累计值就是伤害（§130）
⇒ 全程零伤害。对照组：同一天同图**同样难度**的两局单人房（`00:42` 的
`#5` / `#6`）都在进图 **22 秒**后开始出 `0x0410` 并通关。
⇒ 不是「打不动」，是「打不了」。

而且服务端在 boss 房里**既没收也没发任何包**（两局字节级一致）⇒ 病在客户端。

## 查到什么（§64）

boss 阶段 `[boss+0x2a8]` 构造时 = **-1**（石壳护体、免疫伤害）。
把它抬成 0 的全客户端**只有**任务脚本命令 `$공략포인트`（处理器 `0x4a76ad`），
而它只出现在 `Data/Quest/Quest02/Quest02Tracing` 那份剧情里。

放那份剧情的每帧检查 `0x4a7080` 要求：没有剧情在播 **且**
`boss->vf_154(4)`（`0x4b5a04`）为真，而后者判的是
**`[boss+0x2b0] == "birth"`** —— 只活 `BirthTick`(=120) 个游戏刻 ≈ **3.6 秒**
的瞬时动画状态（游戏刻追墙钟，`0x42b4c3`）。出生动画一结束，
`vf_140("think")` 在 `0x4b1c54` 看阶段还是 -1 就切成 `"idle1"`，
`vf_154(4)` 从此恒假 ⇒ **剧情永远不放、阶段永远 -1 = 永久无敌**。

Quest02 的 `$createboss` 偏偏在入场剧情倒数第 6 行，后面还有
`fadeout 3000` / `clear` / `fadein 3000` / `wideoff`，这期间检查被挡；
这张图上还有 `Quest02Lava` 之类会插队的剧情。加起来盖过 3.6 秒就永久错过
⇒ **有时**。

只有 Quest02 是这个形状，其余六关各有各的活法（§64 那张表）。

## 改了什么

`hook/bshook.c` 新增 `try_patch_draka_tracing_gate()`（挂进 `patch_thread`）：
`0x4b5a04` 那 20 字节原地换成 `cmp dword [esi+0x2a8], -1` / `je` / `nop×11`
⇒ 判据由「boss 正在放出生动画」变成「**弱点还没点出来**」（D70）。
逃生门 `BSHOOK_KEEP_DRAKA_TRACING_RACE=1`。

`hook/build.bat` 重编（`bshook.dll` + `bsloader.exe` 一起，铁律 6）。
**服务端一行没改。**

  `logs/bshook_20260910_101425_pid25216.log` 有
  `PATCH   ★岩浆巨龙弱点剧情 @ 004B5A04` ⇒ 特征串对得上、字节写进去了。
  跑完 `stop.bat` 收干净。
