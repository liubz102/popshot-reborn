# 2026-09-09 会话 08 —— 修「自己装备的装备别人看不见」

## 用户要什么

「老游戏的装备合成功能开发，请接着之前的成果继续推进。
现在自己装备的装备别人看不见，帮我修复。」

## 查到什么（§63）

**根因一句话**：`0x030b gspSlotEquippedList` 全服务端**只有一个发出点**
（改前 `gameserver.py:6570`），而它永远是
`座位 = self.my_seat`、`清单 = self.account`、`收件人 = self`。
⇒ 每个客户端手里只有**自己那一格**的清单，别人那五格恒空 = 没穿装备的样子。

**顺带把「外观」那条路查穿了**（原来只知道 `0x030b` 管加成和「人物选择」）：

```
0x030b → 0x406ea1 ├ 写 [LobbyStage + 座位*4 + 0x250]   ← 加成读的那一格（§1）
                  └ 0x406f42 ├ 0x404ff6 → [+0x1d0+座位*4]  那一格的 3D 角色
                             ├ 0x506251  清掉身上已挂的
                             └ 逐件 0x505bb9(itemId) → 0x5059c0 挂上去
```

三条关键事实：

1. `0x505bb9` 查的是 **`[0x72e1e0]`**，不是服务端喂的 ItemDB `[0x72e1dc]`（§28）。
   `[0x72e1e0]` 由 `0x41652d` 在**启动时**从 pak 里的 `ShopItem-Chn.ini` 读进来
   （文件名串 `0x6602a8` → `0x55e7f0` 那个 pak 加载器）⇒
   **服务端只要给 itemId**，观察者的客户端也**不必**先查过这件物品的定义。
2. 角色限定在 `0x505bb9` 里现算（`itemId/1e6-1` 对 `[角色+0x2b0]`）⇒
   一次把某人三个角色的装备全发过去是安全的。
3. 战斗里是同一份：`0x493258` 建完座位角色紧接着就是 `0x406f42`。

**⚠ 最容易漏的一条**：清单存在 `LobbyStage`（`[0x72e29c]`）上，**跨房间活着**，
没人覆盖就一直在；而 `0x0301` action 0 建完 3D 角色立刻调 `0x406f42`。
⇒ 某一格一换人就得重发，**bot 那一格也要发（空清单）**，
否则 bot / 新人穿着上一个坐这儿的人的装备。

## 改了什么（D69）

`server/gameserver.py`：

| 函数 | 干什么 |
|---|---|
| `build_seat_equipped_frame(seat_index, account, reason)` | 组包。★ 入参从「连接」改成「**存档**」—— 拿错存档在类型上就说不通了 |
| `seat_account(seat)`（静态） | 座位上那个人的存档；bot / 假座位 = `None` = 空清单 |
| `send_room_equipped_lists(room, reason)` | 房里**每一个有人的座位各一发**，发给我自己 |
| `broadcast_seat_equipped_list(room, seat, reason, to_self)` | 某一格的清单发给房里的人 |
| `broadcast_slot_equipped_list(reason)` | 上一个的薄壳：我这一格 → 其他人（`to_self=False`）|

挂了六处：

1. `enter_room()` —— 进房那一批里，每个有人的座位各一发（原来只发自己）；
2. `announce_join()` —— 新人的清单广播给房里其他人，**排在 `0x0301` action 0 之后**；
3. `on_req_equip_item()` —— 穿 / 脱之后本人 + 广播；
4. `bot._add_one_bot()` —— bot 占座后广播一发**空清单**；
5. `leave_game_result()` —— 结算看完回房间，每个有人的座位各一发（原来只发自己）；
6. 调试通道 `equip` / `unequip` / `sync-account` —— 本人 + 广播。

**没做**：买角色卡之后不广播（角色卡和别人看得见的外观无关，而且买东西时人不在
房间里，广播是恒定空操作）。理由记在 D69。

## 结果

- 两套运行时（3.14 / 3.8）全量 **3031 项全绿**，新增 5 项
  `test_room.EquipmentVisibilityTests`：穿上 / 脱下会到别人那儿、第三个人进房拿到
  全部座位、回房间重发每一格、bot 占用旧座位拿到空清单。
- 改的 4 个 `test_room` / `test_gameserver` 老断言都是「多了那几发 `0x030b`」，
  不是行为回归。
- **没打包、没提交**（用户自己管履历）。
