## 踩过的坑（省下别人的时间）

- ★★★ **差点把 `re/packet_api.md`（19 万字符）弄丢**：用
  `io.open(p,'w',...).write(s)` 改文件，`open` 先**截断**、`write` 才因为
  字符串里有**孤立代理对**（源码里写 `"🔍"` 想拼 🔍）抛
  `UnicodeEncodeError` —— 结果原文件变成 0 字节。
  靠 `git show HEAD:re/packet_api.md > ...` 救回来了（该文件已提交过）。
  ⇒ **改仓库里的文件一律「写 `.tmp` → 回读校验 → `os.replace`」**，
  样板见 `scratchpad/patch_packet_api.py`；emoji 直接写字面量，别拼代理对。
- Bash 里内联 python 单行脚本，正则含 `$` 会被 shell 吃掉 ⇒
  写到 scratchpad 的 `.py` 文件里再跑。
- 读韩文/中文字符串时 `print` 会撞 GBK 编码错 ⇒
  脚本开头加 `sys.stdout.reconfigure(encoding='utf-8')`。
