# 2026-09-07 会话 13 —— 复核用户手改的掉落表 → 按原版口径整体重做掉落 + 配方（D49）

## 上半场：复核

用户手改了 `server/data/drops.json`（62 → 48 条），要我查漏掉落 / 不合理。
按 `quest_materials()` 的口径算每关每档每种材料的期望产出，对 122 条配方：
**没有漏掉落**；但 18 处「难度越高反而不掉」（boss 普通档材料只在普通掉、
不死鸟之羽 / 橡皮管 / 制作书只挂某一档）、3 种材料掉了没配方用
（制作书高级 / 破碎的军服 / 太阳结晶）、第 7 关简单的原版基线被改成橡皮管但备注没改。

## 下半场：用户拍板了原版口径，整体重做

用户的记忆：困难和普通掉**不同档**的材料、困难不掉普通那档；名字有特点的材料
只在特定 boss 关掉，普通低档 / 困难高档、100%；简单只掉通用材料；中高难度
还掉通用材料，**一局一般就掉两种**；同风格装备用同风格材料
（白银 ← 龙之血 + 熔岩 + 红珠，黄金 ← 龙之精华 + 更多熔岩 + 红珠；凤凰分高低两档）。

做法：改 `tools/gen_listing.py` 的表（掉落 `SPECIAL` / `GENERIC` / `EASY_BEAD` /
`PVP_BEADS`，配方 `SET_LINES` / `CHAR_SET_LINES` / `KNIGHT_LINES` / `RING` / `PET`），
`check_monotonic` 换成 `check_tiering` + `check_recipes`，`--apply` 默认只写
recipe / drops（items / shop 不一样时跳过，`--all` 才覆盖）。配对依据是
16 张套装图标（`Images/Shop/<韩文名> 셋트.png`）和名字，表在 D49。

第二轮（用户看完第一版）：**每关一种独占的通用材料、三档都一样** —— 青铜管归
机械青蛙、浮游石归鲸鱼战舰（简单 / 普通也掉）、橡皮管归秘密基地（顶掉青铜管和
熔岩碎片，原版基线 0114 因此不保留）。凤凰两套的矿料跟着改成橡皮管，鲸鱼战舰
系的戒指 / 宠物改用浮游石。

第三轮：各关的独占通用材料在**对战**也掉（赢了每样 15%，`PVP_GENERICS`），
特殊材料不进对战；制作书只给初级。

## 结果

- `--apply` 三次：掉落 52 条 / 合成 122 条，items / shop「不变」；旧文件留
  `.bak-20260907-175603`（用户手改版）和第二次的 `.bak`。服务端热重载：
  `shopcfg.drops()` 46 条无警告。
- 每套装备材料全在一关（简单打珠子，普通 / 困难打特殊材料 + 矿料），
  一套 9 ~ 31 局（中位 20），一件 4 ~ 6 局。26 种材料（卡片除外）每种都有配方用。
- 第 7 关 boss 还是机械青蛙（`Quest07/Map03Intro.txt`），凤凰材料没有对应的
  boss ⇒ 放最后一关是我们定的（§42）。

## 收尾：把四份运营数据搬进模板（D50）

用户要新下载发布包的人也拿到这份数据。做法：`gen_listing.py` 的设计表和生成逻辑
整个搬进 `server/shopdefaults.py`（随包走，`build-common.ps1` 的必带清单加了它），
`shopcfg.default_*()` 变成它的切片（旧的 `RECIPE_LINES` / `DEFAULT_MATERIAL_DROPS` /
`_recipe_seed` 那 270 行删了），`gen_listing.py` 只剩壳。名字的兜底从「磁盘上的
items.json」改成 `shopcfg.item_name_zh()`，只差一个 `30005 橡皮管` 补进 `NAME_BY_ID`。
去重去掉的 108 件复制品改成跟孪生件同等级，`--apply --all` 同步了物品库
（差的 36 件只差等级），四份 json 和模板**逐字节一致**。
`RealDefaultsTests` 改成钉 484 / 122 / 52 + D49 口径 + 每种材料有用有掉；
`BackfillTests` 那条「默认表没有的条目」换成小表里没系列号的武器 `1120051`。
两套运行时全量 2869 项都绿（3.14 84 秒 / 3.8 154 秒）。
★ 便携运行时带 `_pth`，`-m unittest` 找不到模块，要走 `server/run_tests.py`。
