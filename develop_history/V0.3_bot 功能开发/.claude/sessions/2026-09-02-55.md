# 会话 55 —— 两条遗留：天花板判定只看落点 + 增量边缓存

2026-09-02。用户：「卡顿问题现在好多了。天花板判定只看落点、增量边缓存
两个遗留问题请继续帮我修复。」

## 做了什么

### 1. §169 / D128 —— 天花板判定只看落点

* `botmove._ceiling_between()`：沿这一 tick 的位移线段**逐整数行**扫，
  x 按线段线性插值；第一处「挡得住而且不是站立面」的格子之前那一点就是终点，
  **横向也一起停**。`_air_tick()` 的 `elif vy < 0` 那一支换成它。
* 两个不扫的口子：**蹭上坎**的那一 tick（`climbed` 旗子，保住 §95）、
  以及**人已经嵌在地形里**（脚下那格实心且不是站立面 ⇒ 先跳过一路连着的实心）。
  第二条是被端到端用例 `test_it_crosses_the_lava_pit_on_the_real_map` 逼出来的：
  `Quest02_1` 岩浆坑左沿是缓上坡，bot 身体摆在 453 而地面在 444，
  不放这个口子它一辈子过不了那个坑。
* 性能：直接逐格扫泛洪慢一倍（1034 -> 2334 ms）。新
  `mapdata.MapTerrain.coarse_clear()` 借弹道粗网格先证「这一小段整个是空的」，
  97% 的上升 tick 到此为止 ⇒ 最终 1034 -> 1391 ms。
* ★ 顺带纠正了 D127 末尾那句话：`0x50e4e9` **全程序只有一处调用**，
  而且挂在 `0x493d00()` 为真的死分支下，不是正常对局走的路。正常那一支的
  `0x50d9a7` / `0x50e40a` / `0x50d404` 同样逐格推进 —— 结论没变，出处换了。

### 2. §170 / D129 —— 增量边缓存

* `botnav` 的一个落脚点固定 **17 次尝试**（`_ATTEMPTS`，顺序写死），
  每次尝试用 `_Trace` 记下自己摸过的那一片（外接矩形 + 最大 `|vx|`，
  再往外放一圈**探针够得着的距离**，全是角色自己的尺寸）。
* `node()` 建变体那一格时，先在**母地形**和**「全碎」那份**里挑差得少的当继承源，
  逐条问「这一片被碎掉的那几件碰到了没有」：没碰到就整条搬过来。
* 足迹存 16 像素一格的格号（`array("i")`），不存浮点 —— 9.4 MB -> 5.0 MB。
* 实测碎一件之后整图泛洪：`Esperan03` 1576 -> **198 ms**、
  `Iceria02` 1617 -> **51 ms**、`Festival02` 922 -> **92 ms**。

### 3. §171 / D130 —— 上机之后抓出来的「bot 站着不动」

用户实机反馈「所有 bot 全都突然不动、过几秒恢复」「bot 经常卡住不动」。
**先把网络排掉**：房间循环两局都跑满格（4764 / 7501，一格不落）、
bot 心跳间隔中位 128 ms p99 ≤144、发包最大空档 180 ms
⇒ §163 / §166 没回来，bot 是真的站着。

真因是 `_walk_to()` 里 §152 那条兜底排在规划分支**后面**：
「往前一步塞不进去」时三条问路判据一条都不成立 ⇒ 一张规划单都不递
⇒ `CamelCulvert04` 上 bot1 在 (279,990) 站了 **87 秒**到局终。
已把 `crack` 并进 `if blocked or bottomless or vertical or crack:`。

★ 量法（下次直接用）：从 `server.out` 的 `→ 发出` 十六进制里解 `0x4001`
心跳的位置和**按键掩码**，按「位置连续不变」分段 —— 掩码 0 = 自己决定
站着、非 0 = 想走却走不动，两种毛病完全不同。脚本思路记在 §171。

### 4. §172 / D131 —— 「一进游戏 bot 都不动，我一动它们才动」

用户第三轮。和第 3 件是**两个不同的门**。心跳量出来：`CamelCulvert04`
bot1 在 (1285,853) **27 秒一步没挪、一枪没开**，而真人第一次挪窝是开局
+17.7 s —— bot 确实是跟着真人动才动的。

闭环：唯一的路被罐子堵着（完整地形 A\* 一格都算不出来）⇒ 走不了；
「视野里有敌人就先不打罐子」⇒ 不许打；站着 ⇒ 签名不变 ⇒ 闩不松。
① `RouteChoice.stranded`（后台传出「完整地形上一格都走不了」）->
`machine.path_breakable_only` -> `_breaking_now()` 无条件开打；
② `_nav_signature()` 带上 `terrain.alive`，罐子翻转真能松闩。

★ 这是 §160 家族第三例，形状是「某个『站住』分支产生的状态，恰好是它
自己解锁条件的否定」。下次遇到「bot 不动」先照这个形状找一遍。
