## 1. 「用 gun 命令，很多角色都无法切换 2 号武器」

### 结论：**D49 / §70 的前提是错的**（见 §72 / D53）

会话 19 拿语料残差判「`AppleGrenade` / `FlamingBottle` 那几类在收方多吃
句柄」，于是把 `usable` 收紧成只放行 `CreatingClass=GeneralBullet`，
16 个角色里 10 个的 2 号槽因此消失。

**那份残差量的是「射手自己那台机器」。** 逐指令读下来，分裂弹 / 火墙 /
炮台的创建点**全部**套在 `IsMine`（`0x50d294`）里 —— 而 bot 的弹体在
**任何一台客户端**上 `IsMine` 都是假的（§42 第 3 条就是这么说的，
会话 19 自己写的），所以那些额外对象**一个都不会被造出来**。

顺路查实的：

* 每个弹体子类的 `Tick` 头一句都是 `call 0x47de6a`（基类 Tick）——
  飞行本身完全一样，子类只加特效位置 / 引信 / 分裂；
* 全镜像搜 `8b 08 8d 51 01 89 10`（句柄计数器 `++` 的字节模式），弹体模块里
  只有 `0x491732`（网络 `OnFire`）和 `0x484924`（PlasmaCannon 自己的
  `vft+0xa8`）—— packet_api 原来写「溅射那一个是 `0x484920` 分配的」
  认错了函数；
* `IsMine` / `IsNeutral` 比的是 **`0x1e` = 30**，不是 20（packet_api 已勘误）；
* `SliceTime` → `weapondef+0xa0`、`SliceCount` → `+0xa4`、`SliceId` → `+0xa8`；
  每 tick 的毫秒数 `[0x6dc528]` = **32**（又一处印证 §47）。

### 代价：引信

`AppleGrenade` / `SeedBomb` / `SliceBullet` 的 `Tick` 里有一个从
`SliceTime / 32` 倒数的计数器，到 0 就**在每一台机器上自爆、不带伤害**
（那一段在 `IsMine` 门**外面**）。⇒ 服务端把它当**射程**用：
飞到目标要的 tick 数够不着引信就不开这一枪（`bot._outlives_fuse()`）。
实测只有角色 3 的 2 号（`SliceTime=1200`）在 1000 单位那一档会被挡住。

### 结果

可用武器 33 → **42 把**；10 个角色三个槽位全齐，剩下 6 个各缺一个槽
（反弹弹 / 炮台 / 等离子炮 —— 都是**飞行**没模型，不是句柄问题；
角色 3 的 3 号是原版 `Damage=0`）。

## 2. 「只有敌人的两个 bot 会打我，我的 bot 队友不打敌人」

`_hostile_humans()` 只扫 `room.human_seats()`。用户那一局是
「真人 + bot 队友 vs 两个 bot 敌人」⇒ 我方 bot 的对面全是 bot ⇒
它「一个敌人都没有」⇒ 一枪不放；敌方 bot 也看不见我方 bot。

改名 **`_hostile_targets()`**，扫所有座位，判据只剩「位置已知 / 活着 /
不同队」。位置一律走 `_seat_body()`，和判命中时 `_battle_bodies()` 同一口径
—— 「挑得中的目标」和「打得中的身体」必须是同一批人（D52）。

★ 个人战房里两个 bot 现在也会互相打，那就是个人战该有的样子。
