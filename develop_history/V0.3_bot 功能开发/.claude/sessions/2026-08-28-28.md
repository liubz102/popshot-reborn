# 会话 28 · 2026-08-28 · 击退

## 用户说的

又试了下，3 号角色的 2 号武器，bot 打我，我会有被击退效果；我打 bot，
bot 不会被击退，只是原地跳一下。请调查一下其他角色或武器还有没有漏掉
击退效果的，一并修复。

## 结果

查明**三处全漏**、全部改了，**没有实机复验**。1584 个单测在 3.14 和 3.8
上都全绿。

### 「原地跳一下」是什么

不是「没反应」，是**服务端把它拽回去**：bot 的位置由服务端说了算，
每台客户端都把它硬同步到心跳报的坐标（§5.6）。挨打时客户端各自按
`Character::OnHit` 把 bot 的模型顶飞了，而服务端这边的模型没动 ⇒
下一发心跳（8 Hz）当场拉回原位。那一下「跳」是原版**甲档无条件离地**
（`0x50f947: mov [char+0x128], 0`）在客户端本地放出来的。

### 击退的机制（§92）

`0x481003` 挂在伤害源的虚表槽 `+0x148` 上，**31 个伤害源类里 30 个共用它**
（唯一例外是新手教程的 `TrainingGrenade`）：

```text
d = normalize(来向) ; d.y -= 0.7 ; d = normalize(d)
push = d × 强度      强度：<10→4 / <20→8 / <40→15 / <80→20 / <160→40 / 否则 1
```

来向四条路各不同：直接命中取**弹体此刻的速度**、溅射取**爆点→身体圆心**、
地面燃烧恒 `(0, −8)`、近身恒 `(朝向×15, −10)`。

收侧 `0x50f7ca` 按伤害分两档：`>= 10` 是甲档（`> 10` 才真给速度，
**无论如何都离地**），`< 10` 且站在地上是乙档（只横着滑 `push.x × 3`，
不离地）。

### 「其他角色 / 武器还有没有漏的」

**`weapon.ini` 里根本没有击退字段** —— 强度只看伤害、方向只看来向。
所以不是某几把武器漏了，是**三件事全漏了**：

1. bot 发的 `rpSplashDamaged` 的 `+13/+17` 一直填 0（溅射 / 火 / 近身三处）；
2. bot 挨打时服务端不结算击退；
3. bot 打 bot 同样两头都没有。

### 语料把整套公式钉死了（13160 发 `rpSplashDamaged`）

* 伤害 1~9 → `|push|` 恒 **4.0**（5637 发）；10~19 → 恒 **8.0**（3908 发）；
  20 起出现 **15.0** —— 五档阶梯一档不差；
* `(0.0, -8.0)` **1164 发** = 地面燃烧那个常量；
  `(±15.0, -10.0)` **1347 发** = 近身那个常量；
* 同一个「包里伤害 20」在生存局配 15.0、在夺分局配 8.0 ⇒ **喂进阶梯的是
  乘模式倍率之前**那个数（顺手又印证了 §90 的乘法顺序）；
* 方向公式拿 38 发**自伤**样本（受害者就是射手，位置有他自己的心跳）对下来
  中位差 **2.9°**、p75 7.5°。

### 唯一要建模的地方：直接命中的来向

`rpExplode` **不带**击退矢量 —— 每台机器拿自己那颗弹体的速度现算。
自造包的一方只能按真人的 `rpFire` 反推：

```text
t = (爆点x − 发射点x) / v.x
y = 发射点y + t·v.y + g·t(t+1)/2      ← 和 ballistics.position_at 同一式
v = (v.x, v.y + g·t)                  ← 和 _shell_velocity 同一式
```

拿「预测 y 和爆点 y 差多少」当匹配分挑那一发；差得超过 120 就当没配上，
**不给击退**（宁可少顶一下，也不要按不相干的弹道把 bot 甩到反方向）。

⚠ 试过但**不够用**的近路：拿「发射点 → 爆点」的弦当速度方向。
客户端逐帧日志 1148 条轨迹量下来，击退方向中位差 0°（直射弹精确），
**但 p90 差 55°** —— 抛射弹整个不成立，而带击退的恰恰是抛射弹。

## 遗留

* ⏳ 要实机验（清单在 `PROGRESS.md`）。
* ⚠ 配不上开火记录的两种：**弹跳过的弹体**（§84 之后闭式解不成立）和
  **拐过弯的追踪弹**（§77）。这两种直接命中 bot 时不给击退。
* ⚠ 乙档在地上那一滑用的是 `botmove.surface_near()`（和火团往外铺同一个
  模型），原版走的是 `0x50d9a7` 那个通用横向移动 —— 贴边的情形可能差一点。
* ⚠ `0x492c96` 的 `[源vft+0x12c]` 和 `0x492cae` 的 `[源vft+0x14c]` 没读，
  那两发是打在**伤害源**上的回调（特效 / 计分？），和位置无关。
* ⚠ 会话 24~27 的验收清单照旧没验过。

## 顺手记一条方法

**「某个效果 bot 没有」先分清是「包里少了一格」还是「服务端少算了一步」。**
这一轮两者都有：溅射的击退是**包里那一格**没填（补上就行），
而直接命中的击退**根本不在包里** —— 收方各算各的，自造包的一方非建模不可。
判据是：拿掉那一格，原版的收方还能不能自己算出来。
