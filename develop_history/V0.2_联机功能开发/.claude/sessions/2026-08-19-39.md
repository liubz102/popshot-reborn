用户报：对战模式新建房间，偶尔随机出现一些隐藏地图（截图是 Festival

## 做了什么

1. **逆出整条链（§221）**，用 `re\BigShot_22524.img` + capstone 逐指令核对：
   - 建房对话框 `CreateRoomNewUI.ui` **没有地图控件**；PvP 建房流程
     `0x43be28` 的 `0x0201` 请求里地图名**恒为空串**（闯关分支才填任务地图名）；
   - 地图是进房后客户端**随机挑**的：`0x468176`（7 个调用点）/
     `0x469c17`（randomMapBtn）→ `0x40b6e5` = `0x40b5d0`
     （模式/等级/人数上限/任务 id 过滤，**不看 OpenLocale**）+ 真随机数取一张；
   - 房间设定「地图」下拉框（SelectPvpMap.ui 的 mapCB = `[dlg+0x594]`；
     themeCB = `[dlg+0x598]`，由 0x463fd7 读选中项索引主题表钉死）的填充

     `1 << [[0x72e320]]` 的掩码测试** —— 这是全客户端第三处、也是最后一处
     对地图记录做地区测试的地方，V0.1 §119 只 patch 了前两处
     （目录加载 0x40b419、任务下拉 0x4368cf）。
   - ⇒ V0.1 解锁 Quest 5/6/7 时按韩国位放进目录的 OpenLocale∈{1,3} 地图

     Garden×2 + Desert×3 + CamelCulvert00/01）能被随机选中，
     却进不了下拉列表 —— 现象完全对上。
   - 顺手排除：`0x463bb7`（OnEvent 开启时仅房主的 mapCB 填充）和
     ladder 选图框（0x464606 起的另一组控件）都不做掩码测试，无需改。

   `0x4653ad` `8B 08 → 33 C9`（`mov ecx,[eax]` → `xor ecx,ecx`），
   19 字节特征串对原始镜像核对过。选「让它们显示在下拉列表」而不是

   且统一口径消灭的正是「三套口径不一致」这个 bug 本身。

## 追加（同日晚）：用户拍板「全部解锁」—— D141，两处掩码判定整个旁路

1. **逐指令核实两处跳转的路径结构**（确保 NOP 安全）：
   - 目录加载 `0x40b428 test / 0x40b42a je 0x40b442`（74 16）：
     不跳 = `0x40b42c` 插入红黑树（0x554ce0 找节点 → 存记录）；
     跳 = `0x40b442` push 1/ebx → `0x40b47a` 析构释放。NOP → 永远插入。
   - mapCB 填充 `0x4653bc test / 0x4653be je 0x4654b3`（0F 84 EF 00 00 00）：
     不跳 = 去重后 AddString；跳 = 跳过本条。NOP → 全部加进列表。
