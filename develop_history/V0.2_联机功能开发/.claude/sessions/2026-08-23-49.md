目录；查清所有受影响的地方并修正引用；**自动更新不许覆盖玩家的
server.config**；支持自动更新的版本未发布过 → 一次性移动、不写迁移逻辑，
随 V0.2.7 重打发布。决策记 **D158**。

## 做了什么

1. **移动文件**：仓库根 `server.config` / `server-ClientFilter.config` →
   `config\`（文件系统移动；git 里的增删留给用户自己处置，agent 不碰 git）。
2. **server/**：`config.py`（`CONFIG_DIR` 常量 + `config_path()`）、
   `versioning.py`（`client_filter_path()`）、`app.py` / `gameserver.py`
   的 --help 文案、`test_update.py` 那条用 `client_filter_path(tmp)` 摆沙箱。
3. **tools/**：`launch.ps1`、`shutdown.ps1`、`serverctl.ps1`、`serverctl.sh`、
   `stop.bat` 注释、`probe-death.ps1`（取证摘抄清单）、`build-menu.ps1` 提示、
   `build-common.ps1`（Copy-ClientFilterConfig src/dst）、
   `build-portable.ps1` / `build-server-package.ps1`（拷贝目的地 + must 自检
   清单升级为三项：`BUILD.ver` / `config\server.config` /
   `config\server-ClientFilter.config`）。
4. **updater/**：`config.c` 探针读 `config/server.config`；`apply.c` 保护清单
   `server.config` → `config/server.config`（★ 用户强调的那条）；selftest 同步。
   e2e 沙箱布局同步，**并给假更新包真的塞进一份模板 config\server.config**
   —— 之前 zip 里没有它，「保护」断言是空转的（zip 里压根没有这个文件，
   跳过与否无从谈起）。重编 + selftest 闸门全绿 + 拷回
   `game_patched\BsPatcherChn.exe`。
5. **hook/**：登录框第二个单选钮 `(IP设置:server.config)` →
   `(IP设置:config目录)`（估宽 ~114px，145px 上限内、比旧文案短，但 §175
   警告仍算数 → 真机排版进待验证表第 56 条）。bshook.dll + bsloader.exe
   成对重编，`test-watchdog.bat` PASS。
6. **仓库文案**：`.gitignore`（`/config/server.config` 忽略根锚定 +
   `!/config/server-ClientFilter.config` 放行）、根 `README.md`、
   `tools\server-package\README.md` 全部指到新路径。只提文件名不提位置的
   注释（ports.h / gen_ports_h.py / relay.py / web/server.py 等）没动 ——
   文件名本身没变。
