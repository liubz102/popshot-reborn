# 会话 20（2026-08-14）—— 捡到道具「道具栏不显示、也用不了」

## 用户报的

> 现在有道具了，走过去后，有捡起的动画和音效，道具也会消失，但是道具栏不会显示新捡的道具，也无法使用

承接会话 19（D109 / §191：服务端往地图上刷道具）。刷出来的箱子能捡了，
但捡到之后那一半是空的。

## 做了什么

### 1. 逆向（结论进 §194）

从 `0x0405` 拾取放行的读侧往下顺：

- `0x551d35` 调 `item->vft[0xd4](角色)`；
- 17 个 PvP 道具类**全部重写了 `vf_d4`**（逐个查 vft，都指向同一个 `0x5224fe`）；
- `0x5224fe` = 「调基类 `0x51f447` → 放特效 → 放音效 → 冒一行提示」；
- 基类里那条「当场生效」的分支要求 `[item+0x2a9] == 0`，而 §191 已经查明
  PvP 道具那一格是 **1** ⇒ **恒不成立**。

⇒ **拾取放行对 PvP 道具只做「箱子消失 + 特效 + 音效」，和用户看到的一字不差。**

再反过来找「道具到底怎么进槽」，三条链各自都只有一个入口：

| 事 | 客户端唯一入口 | 触发者 |
|---|---|---|
| 进 4 个槽 | `Character::AddItem` `0x517037` | 服务端 `0x040b`（`0x55206b`）|
| 离开槽 | `Character::RemoveItem` `0x5170b4` | 服务端 `0x040c`（`0x552089`）**全客户端唯一调用点** |
| 效果生效 | `Character::UseItemEffect` `0x508441` | 服务端 `0x040a`（`0x551d95`）|

按 Ctrl 时客户端（`0x516335`）只做两件事：发一发 `0x040c`（槽位**恒 0**）、
放一声音效，然后**等服务端**。

★ 顺带更正 §193 的「u16」：三处读字段用的都是 `0x5d5984` = `Read(&buf, 4)`，
**是 int32**。

★ `0x040a` 的字段顺序反直觉：处理器的 push 顺序是 F1/F3/F2 ⇒
`UseItemEffect(F2, F3, F1)`，**道具 id 落在第 3 个字段**。
值照抄 `PvpItem::vf_11c` 自己那条 `(id, 0, -1)`。

### 2. 实现（D110）

`server/gameserver.py`：

- 常量：`OP_ITEM_EFFECT/OP_GRANT_ITEM/OP_USE_ITEM`、`GRANTABLE_ITEM_IDS`、
  `ITEM_SLOT_COUNT=4`、`ITEM_EFFECT_ARG2/ARG3`；
- 线格式：`build_grant_item` / `parse_use_item` / `build_use_item` / `build_item_effect`；
- `RoomQuest`：`item_handles`（句柄→物件 id，刷道具和客户端掉落都记）、
  `item_slots`（每座位 4 格镜像）、`remember_item` / `item_id_of` /
  `grant_item` / `use_item`；
- `Conn`：`grant_picked_item()`（拾取放行之后补 `0x040b`）、`seat_conn()`
  （座位→连接，点对点发）、`on_use_item()`（回 `0x040c` + 广播 `0x040a`）；
- 分发器接上 `OP_USE_ITEM`。

`tools/fakeclient.py`：新增 `useitem [槽位]` 命令，三个新包都解成人话。

**两条跟着客户端走的口径**：满 4 格就不发 `0x040b`（客户端 `AddItem` 静默返回）；
槽位序号照包里的来，不写死 0。

### 3. 验证

- 全量测试 **650 → 681 项全过**（净增 31）。
- 端到端：真服务端进程（另起 47911/27999/27998）+ 两个假客户端，
  道具房 `args=(0,0,1)`：
  - alice 捡 10304 → 只有 alice 收到 `0x040b`；
  - alice 按 Ctrl → 她收 `0x040c`，**两人都**收 `0x040a 座位=0 物件=10304 (0,-1)`；
  - bob 捡 10401 → 只有 bob 收到 `0x040b`；他用掉之后两边的 `0x040a` 都写 `座位=1`；
  - 槽空时再按 Ctrl → 零回包。

### 4. 顺手修的既有红

常量还是 60，`test_the_shipped_template_parses_to_the_defaults` 一直红。
按 D107 / §188 和另外三份模板把**模板**改回 60。
根目录 `server.config`（玩家自己那份，20 秒）**没动**。
