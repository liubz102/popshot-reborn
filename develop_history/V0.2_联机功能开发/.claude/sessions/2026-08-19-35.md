# 会话 35（2026-08-19）—— 「第二局打不死人」不稳定复现，探针改成**调试模式常驻**

## 用户报的

「第二局打不死人」这个 bug **不是每次都稳定复现**，刚试了几把都没出现。
要求：把探测脚本改成**调试模式时长期探测**，他本地用 debug 模式玩，
什么时候再遇到了再把 log 发回来。**其他人和服务器暂时都用老版本代码**
（保持能复现的环境，所以这一轮服务端一个字没动）。

## 做了什么

只动了取证这一侧的四个文件，服务端 / 客户端 / 协议**全部没碰**。

1. **`tools/probe_sync.py`**：从「采 N 秒就退」改成能长期挂。
   - `pid` 可以写 `auto`（自己用 `CreateToolhelp32Snapshot` 找 `BigShot.exe`），
     配 `--wait-game` 时游戏还没起来就等着 —— 所以能在**拉客户端之前**先挂上；
   - 时长写 `inf` / `forever` / `0` = 不限时，靠 `GetExitCodeProcess` 盯着
     游戏进程，**它一退探针自己收工**（不留后台进程）；
   - `--log` 自己写文件（UTF-8）并**按 `--max-mb` 滚动**（默认 64 MB × 3 份），
     挂一整天也撑不爆磁盘；
   - 没变化时也每 `--heartbeat` 秒记一行（默认 60），确认探针活着 + 好对时刻；
     时刻从 `HH:MM:SS` 加到 `MM-DD HH:MM:SS.mmm`（长期跑要跨小时）；
   - **换局单独拉一条横幅**（局号 = 队列纪元号，这个 bug 就发生在那一刹那）。
2. **判据重写成 `Watcher` 类**（原来那个 `verdict()` 是无状态的，噪音大到没法用
   —— 上次 15 分钟的日志里 `base >= 上界` 那条几乎每行都在报）。现在按 §216
   的那张表分三种死法，各自**一局只报一次**、换局清账：
   - ①「队列从没激活过」（`+4=0` 而上界在涨）= 事件全程只入队不派发；
   - ②「base 卡住不动」（`live=1`、上界照涨、`base` 不动 ≥ 15 秒）= 消费者
     停在空洞上等永远不来的号 —— **这一条才解释得了「整局零生效」**；
   - ③「换局后几秒 base 就被抬起来」= 上一纪元的心跳漏进来（D131 那条）。
   - **两条防误报**：判 ①② 都要求**对方心跳最近还在推进**（游戏切后台时
     主循环不跑，什么都不动，以前会满屏误报）；探针**中途挂上的第一帧**
     不判 ③（不知道这局已经开了多久，早就推上去的 `base` 不算毒）。
3. **`tools/probe-sync.ps1`**：默认改成**不限时**；新增 `-Background`
   （起完就走，给 launch.ps1 用）和 `-WaitForGame`；Python 选择改成和
   launch.ps1 同一套 `Select-PythonRuntime` —— 原来写死 `runtime\python`，
   **Win7 玩家挂上探针等于挂一个会弹模态框卡死的 3.14**。
4. **`tools/launch.ps1`**：`-DebugLog` 时自动 `& probe-sync.ps1 -Background
   -WaitForGame`（新增 `-NoProbe` 可关掉）。位置在**清残留 BigShot + 拉
   bsloader 之后** —— 探针认 `auto`，提前挂会附到马上要被杀掉的残留实例上。
5. `start-debug.bat` / `probe-sync.bat` 的说明跟着改（两个都仍是纯 ASCII + CRLF）。

## 验证

- 离线自测（`runtime\python` 的 3.14 和 `runtime-win7` 的 3.8 **各跑一遍**）：
  `find_pids` / `process_alive` / `process_path` / 时长解析 / 参数解析，
  加上 `Watcher` 的三条判据 + 两条防误报 + 换局清账 + 不判自己座位，
  以及 `Sink` 的 header / 追加不重复 / 滚动 / `keep` 份数 / 上限比 header
  还小时不爆栈。全绿。
- 端到端（拿 `cmd.exe` 复制成 `BigShot.exe` 当靶子）：探针先挂 → 等 →
  游戏出现后附上 → 游戏退出后自己收工，日志四段齐全。
- `launch.ps1` 新增那一段抽出来单独跑：`-DebugLog` 挂、`-DebugLog -NoProbe`
  不挂、普通模式不挂；`&` 调用的脚本里的 `exit` 不会带走 launch.ps1（实测过）。
