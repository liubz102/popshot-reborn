## 渲染链（§235.2，避开 res://）

素材 rc 嵌 exe（RCDATA，资源名 = 原 DLL 名；**rc.exe 会把资源名的引号算进
名字**，不能加引号）→ 运行时解到 `%TEMP%\popshot-ui-<pid>\`（BINARY\ 子目录
保留 → 相对引用天然解析）→ 三段逐级回退：
①`Navigate file:///` ②`about:blank+document.write`（BINARY/名 → data:URI、
link css → 内联 style）③`ui_native.c` 原生控件（CONFIRM/MESSAGE 模态退化
MessageBox）。`--ui-mode 1/2/3` 强制档位；`--preview` 真窗口假进度跑一圈
供截图。三段截图在 `logs\updater-ui-preview\`：file:// 档完美复刻原版布局。

纯 C OLE 宿主（不用 ATL）的坑全在 **vtbl 槽位顺序**：IOleClientSite 有
GetContainer/ShowObject、IDocHostUIHandler 有 OnFrameWindowActivate、
IOleInPlaceFrame 的 TranslateAccelerator 在最后且 RemoveMenus 只有单参数
（HMENU）、TransformCoords 第二参是 POINTF* —— 一律照 `%Windows Kits%\Include\
10.0.26100.0\um\*.h` 的 vtbl 定义逐个核对（/W3 的 C4028/C4113 会把错位暴露
出来，最终零警告）。另：CRT printf 的 %ls 在 C locale 下中文变空串 →
log.c 自写格式化器（%ls→wide_to_utf8、%d/%u/%ll 手写）。

## 流程（§235.3）

`updater\src\main.c` 编排（worker 线程 + UI 线程 PostMessage）：探针（cipher
向量与 server\simple.py 对拍；本地版本编码不合法按 311 上报）→ manifest 手写
解析（fail-open）→ WinHTTP 下载（流式 sha256[CNG]、进度/速度/ETA、可取消、
按哈希缓存复用）→ 等游戏退出（超时用 MESSAGEL 原版框问玩家后强杀）→ 停本机
服务端/中继（**exe 完整路径 == 本包 runtime\python.exe** 精确匹配 + 树杀；
两条 runtime 路径都查，不再需要 RtlGetVersion 选分支）→ 写权限试探，不可写
才弹**原版 CONFIRMRUNADMIN 框** → runas 重跑（--zip/--target-version 传缓存）→
staging 同盘整包解压（zip 损坏在搬动前暴露）→ PROTECTED_PATHS 跳过 → 逐文件
MoveFileEx 重试 + 改名让位（改名前先清同名 .update_old 防二次更新挡道）→
**BUILD.ver 最后写** → 完成态「更新完成……请运行 start.bat 重新启动游戏」+
ChangeButton，**不自动拉起任何程序**。
