# 会话 19 —— 内置 Python 与便携发布包（2026-08-08）

## 目标

让当前成果物复制到没有安装 Python 的全新 Win10/11 x64 后，完整解压即可双击启动。
采用「便携目录 + 官方 Python embeddable」，不做 PyInstaller 单文件冻结。

## 改动

* 下载并校验官方 CPython 3.14.3 x64 embeddable，放入 `runtime\python`；
  上游许可证和来源 / SHA-256 说明一并保留。
* `tools\launch.ps1` 从硬编码 `C:\Python314\python.exe` 改为项目相对路径
  `runtime\python\python.exe`，且不允许回退到系统 Python。
* 新增 `README.md`：运行、关闭、迁移存档、可写目录、GameGuard 和杀软注意事项。
* 新增 `tools\build-portable.ps1`：生成精简便携目录，可选 `-Zip` / `-IncludeSave`。
* `.gitignore` 忽略生成的 `dist\`。

## 发布结果

便携目录  dist\PopShot-portable-win64       389.3 MiB

默认发布物不含 `accounts.json`，避免把可能存在的明文账号口令带出去；个人迁移
存档时运行 `build-portable.ps1 -IncludeSave`，或单独复制该 JSON。

## 验证

* 两个 PowerShell 脚本语法检查通过，且均保持 CRLF + UTF-8 BOM。
* 内置 Python 能导入 socket/threading/json/zlib 等必需标准库。
* 内置 Python 跑服务端 **176 项测试全过**。
* 从生成后的发布目录启动认证服和游戏服，分别监听备用端口 47612 / 27899，
  两者均成功接受 TCP 连接；只停止了本次测试创建的进程。
* 关键源文件与发布副本 SHA-256 一致；`Debug` / `Dump` / 当前存档均未混入。
* ZIP 通过 `7z t` 完整性检查。
