## 做了什么

### 1. ★ 教程完成 flag 精确定位并接入账号 JSON

静态确认 `Packet_gspRepLogin::Deserialize`（`0x54c35c`）的第 7 个业务 `int32`
（包对象 `+0x28`）最终写入 `[0x72e2a4]+0x64`；大厅在 `0x43b357` 比较它：
`>= 3` 直接跳过新手教程弹窗，`< 3` 才显示并强制进入训练场。

实现了 `server/account_store.py` 与 `server/data/accounts.json`，对外只存语义字段：

```json
"tutorial_completed": true
```

游戏服组登录应答时编码为 `3/0`；认证服记录当前 localhost 活动账号，未知账号自动建档。
预置 `testuser/testpass` 的教程状态为 `true`。持久化、默认值和协议编码 3 项测试通过。

### 2. 修复首次实机验证中的后台日志崩溃

实机启动时客户端曾每约 0.2 秒重连 27799。根因不是协议：Windows 后台重定向给 Python
stdout 选了 GBK，游戏服打印 `✓` 时触发 `UnicodeEncodeError`，连接处理线程在版本握手后退出。
认证服和游戏服启动时现把 stdout/stderr 固定为 UTF-8。修复后日志确认 `testuser` 的教程状态
确实编码为 `3`，客户端也接受登录包并进入图形初始化。

### 3. 建房前置应答

- `0x0201 gcpReqCreateSession`：精确确认服务端成功包为
  `{ int32 result=0, int32 session_id=1 }`，已接入。
- `0x0311 gcpReqQuestRecord`：确认客户端固定访问六项 `int32` 且不检查长度；安全空记录必须是
  `n=6` 加六个 0，已接入，不能直觉性地回 `n=0`。

### 4. ★ 普通/闯关开局握手闭合

修正了早先的 opcode 偏一错误并静态闭合完整因果链：

```text
客户端空 0402
  → 服务端 0401 TriggerCountGame(result=0)
  → 客户端第二个空 0402
  → 服务端空 0402 + 0412 RepCountDown(state=0)
  → 约 6 秒后客户端空 0400
  → 服务端 0400 PrepareGame(seed=0)
```

`server/gameserver.py` 新增显式单客户端 `StartGameHandshake`，只接受正确状态、正确空载荷，
过滤提前/重复/畸形包；固定 seed=0 保证本地复现。

### 5. ★ 房间类型与 `0x0416` 歧义解决

精确解析 `gcpReqCreateSession` 的三个 UTF-16 字符串、option 与变长 `SessionDescriptor`；
由三个建房对话框的静态赋值确认：

```text
descriptor.type 1 = 普通
descriptor.type 2 = 闯关
descriptor.type 5 = 天梯
```

闯关 type=2 与普通房一样发空 `0x0402`，可直接使用上述状态机。空 `0x0416` 只属于天梯请求；
反方向同号包却是 `Packet_gspUpdateQuestDifficulty { int32, int32 }`，绝不能回显。
每次建房会重置状态机，解析失败记录精确诊断但仍回最小成功包。

Python 语法检查通过；账号与游戏服协议合计 **15 项自动测试全部通过**。

### 6. 实机画面被系统级 D3D9 回归阻塞，并缩小到显示拓扑

客户端在图形初始化时报“图像引擎初始化失败”。独立 `tools/d3d9_probe.c` 排除了客户端、hook
和协议：最小 HAL、REF、默认 D3D9On12、显式 D3D12 WARP→D3D9On12 都无法建立 D3D9 设备；
D3D12 WARP device/queue 本身能建。

探针增加 adapter/display 输出并分别编译 x86/x64。两者均直接枚举 RTX 3070，但都返回
`D3DERR_NOTAVAILABLE`，排除仅 32 位驱动组件故障。当前 `DISPLAY1` 下物理内屏
`SHP14EC` 与虚拟目标 `XMD009A` 同时 active/attached，系统另有多组 GameViewer/Meta 虚拟输出。
这与显示拓扑是目前最强相关项，但必须由用户切换到“仅电脑屏幕”后复验才可坐实。

按 D027 不从脚本自动禁用显示设备，避免误禁 NVIDIA 或令用户失去画面。
