## X13 · bot 认识移动平台 —— 云桥的鲤鱼（用户 2026-09-22）

**需求**：会话 29 补的移动平台碰撞实测无效，bot 的手雷照样穿过「云桥」中间的鲤鱼；找不到同步办法就用 hook 发同步信号。

**查明**（§74）：① 那套判定是死代码（`room.started_at` 应为 `room.quest.started_at`，从未启用）；② 相位原点 `t0`
走 `GameContext+0xe0` 不是墙钟、协议里没有同步包、多人各差一个载图耗时；③ `.map` 每个对象自带 `t_off` / `rel`，提取器丢了。

**做法**（D55）：hook 在 `0x511d97` 记 `(link, t0, t_off)`、每秒报（`MSG_MOVER_PHASE` kind 7）→ 中继原样转 →
`Conn.note_mover_phase` 存 → `bot._mover_clock` 按**房主**报的取（房主掉线随大厅转移逻辑换人，没报退回开局估计）；产物 FORMAT 8，
`Mover.rider_center()` 按 rider 加 `t_off` / 相对模式。守卫：`test_moverphase.py` / `test_mappath.py` / `test_patchsites.py`。

**明确不做**：不改 `.map`；不在服务端猜载图耗时；不钩 `GetPos` 每帧报位置。

## X11 · 升级到 V0.4.1 时，36 把新武器自动补进运营配置（用户 2026-09-20）

**需求**：云上跑着 V0.4.0，`server/data/` 是生产数据。换上 V0.4.1 的包之后，服务端要
**自己检测**这 36 把武器（18 自定义 + 18 原版隐藏）在不在 `items.json` 里，缺就补；
**隐藏武器自动上架商店，自定义武器不上架**。

**为什么不会自己发生**：`ensure_files` 对已存在的配置一律不覆盖（D7）——
云上的 `items.json` 早就落过盘，新加的物品永远进不去；而手动出口
`shop-backfill apply` 走控制通道，云上那个口默认是关的。

**做法**（D48 / §56）：`shopcfg.backfill_new_weapons()`，开服在
`app._report_shop_config()` 里跑一发。判据是「物品库里没有 = 这台服务器从来没见过它」
（物品库那一页没有删除键），**每次开服都跑、天然幂等、不设标记**；货架只给
**刚进物品库的那一批**补行，运营删掉的不会自己回来。上不上架照 `default_shop()`。

**已核过**（拿用户下载回来的云端 data 副本跑的）：808 → 844 件，495 → 513 行货架，
上架的正好是那 18 把隐藏武器，自定义武器一把没上，第二次跑是空的。

**需求**：提示框只有 5 行、装不下两套数值，原先一刀切只画 PVP。改成按玩家所在场景走 ——
**大厅的商店页 / 仓库页画 PVE**（首行「仅显示PVE属性，PVP的请看管理页」），
**待机房间里那个快速换装的仓库画该房间的模式**（首行跟着变）。

**查明**（§52）：大厅仓库 / 商店页仓库格 / 房间快速换装背包是**同一个 `UiCabinetToolTip`**
⇒ 一处补丁通吃；而仓库提示框的文字被客户端缓存死（§39），服务端单独做不到。

**做法**（D45）：服务端把算好的整段文案经新 opcode **`0x0F02`** 推给 bshook，
bshook 在绘制点 `0x4554e7` 按物品 id 换字符串指针（不碰 ItemDB、不碰堆所有权）。
`item_desc_zh(mode=…)` 缺省 PVE ⇒ `0x0500` / `0x0501` / `0x0508` 自动全变 PVE。
下发挂在登录 / 建房 / 进房 / 改模式 / 离房 / 被踢 / 管理页保存七处，带「内容没变就不发」的闩。

**顺带解掉**（用户同一轮点的）：管理页改完说明文，自定义武器的仓库提示框**不用重登**了。

**明确不做**：合成提示框（`0x45ff1b`，同签名）不打 —— 它只在大厅，画 PVE 就对；
不抬版本号；**一个游戏资源都不用重打**。⚠ 但 `bshook.dll` 变了 ⇒ 客户端包要一起发。

## X8 · 自定义武器开放「追踪」参数（用户 2026-09-20）

**需求**：原版只有个别武器带追踪（卡希尔 3 号 / 爱琳的蝴蝶 / 瓦尔基里），
用户要**任意一把自定义武器都能自己设追踪**。

**查明**（§50）：这是「12 格变 14 格」，不是新机制 —— 开关就是 `HomingAngle != 0`
（记录 `+0x78` i32 / `+0x7c` f32），而且 `Projectile::Homing` 挂在所有弹体类共用的
`BulletObj::Tick` 上 ⇒ 18 把（含 2 把手雷、2 把火瓶）全都能追。

**做法**（D42）：`weaponcfg.FIELDS` 末尾加两格 + `bshook.c` 的 `WTAB_FIELD[]` 加两行，
`WIRE_FORMAT` 2→3（**必须重编 dll 并连客户端包一起发**）。范围 0~1300 / 0~1000（用户定）。
另加两样：每格「0 代表…」的灰字（只写核实过的五格）、和跨格判据「填了转向就要填距离」。

**明确不做**：子弹药（碎片 / 火墙）不单独开放；不加「开启追踪」勾选（填 0 就是关）；不抬版本号。

## X3 · 9 把「自定义」黄金武器 + GM 页可调属性 / 说明文（用户 2026-09-19）

**背景**：前人 PR（`2245b8c7`）直接改了泰尔四个左轮小节的原版数值，用户判它破坏平衡，改思路：
**原版武器一律恢复原样且以后不再改**（`test_weaponini` 钉着前 221519 字节的 sha256）；
另给泰尔 / 卡希尔 / 布洛克各加 1/2/3 号共 9 把自定义武器，建模 / 贴图 / 弹体 / 特效全部参考爆裂 3、
