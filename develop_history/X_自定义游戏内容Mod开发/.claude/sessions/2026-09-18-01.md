## 顺手修的几件（都不是这次的题，但都在同一条路上）

- **两条测试往仓库里写文件**：`test_chrprops` / `test_weapondata` 的 `store()`
  往 `HERE` 写临时 json —— 而 `run_tests.py` 的文件头正把「没有任何测试往仓库里写文件」
  当成并行的前提。改成 `tempfile.TemporaryDirectory()`。
- **`tools/` 挂 sys.path 的顺序有雷**：`test_pkn` / `test_notice` 用的是
  `insert(0, TOOLS)`，而 `tools/` 和 `server/` 有**四个同名模块**
  （`mapdata` / `chrprops` / `shopdata` / `weapondata`）⇒ 同一个 worker 进程里
  跑在后面的分片可能 import 到离线工具那一份。两处都改成 `append`。
  （`test_chrprops` / `test_weapondata` 早就用 `importlib` 绕开了，注释里写着理由。）
- **6 条编译期 `SyntaxWarning`** 被 `__pycache__` 遮了很久（`server/bot.py` ×4、
  `botplan.py`、`versioning.py`，都是 docstring 里的 `A\*` / `updater\src`）。
  搬家让 pycache 全失效，它们一次性全冒出来。按仓库里其余 23 处的写法补成 `\\`。
- PROGRESS.md 里有个**真的退格符**（`hook\build.bat` 被写成了 `hook` + `\x08` + `uild.bat`），
  改这段时顺手修掉；扫了一遍 `.claude/*.md`，没有别的控制字符。
