# 2026-09-19 · 会话 06（X5）—— 开放中文版漏掉的 18 把 3 级武器

## 用户问的

「刚加了 9 个自定义武器，模型是照搬原版爆裂 3 改色的。有些武器游戏里没有、管理页物品库也看不见，
可 agent 却找得到完整模型 —— 比如物品库只有重机枪 爆裂1/爆裂2，agent 却找到了重机枪 爆裂3。
为什么？还有没有别的「有模型但没开放」的武器？有的话尽量都开出来。」

## 查明的（→ §45）

- 中文版客户端读 `Data/ShopItem-Chn.ini`（`Chinese.ini` 的 Data 重定向只有 ShopItem / EquipBonus / TipMsg），
  它比韩版 `ShopItem.ini` 少 **622 条**；武器差 **72 节 = 18 件 + 54 条期限售卖形态**。
- 那 18 件 = **1 号槽和 3 号槽的 `D3/R3/F3` × 3 角色**。2 号槽的 3 级中文版有，**日版三档全没有**
  ⇒ 各区上线取舍，不是数据损坏。
- `weapon.ini` **不在重定向表里** ⇒ 18 个小节原样都在；网格 / 弹体图 / amf / efx / 贴图 / 音效 /
  HUD 图标（都是 3 帧）/ 商店图标 **逐项核过一件不缺**。
- `Images/Shop` 891 张里「三份表都没引用的武器图标 = 0」⇒ **原版武器的缺口只有这一处**。
