# 2026-09-26 会话 41 —— 设了代理时 UDP 旁路没了 → SOCKS5 经 UDP ASSOCIATE 照走（X15）

## 用户说的

「选择远程服务器并设置了代理时，udp 连接好像就没有了。本机起了一个测试用的 socks5 代理 `127.0.0.1:10808`，
应该已经配置了支持 udp 转发，但代理显示没收到 udp 流量。我希望用代理时也要支持 udp。并且 bot 的位置信息发送给其他真人时也要走 udp。」

## 查的过程（结论在 §108）

1. 先对着 10808 发了一次 SOCKS5 握手 + UDP ASSOCIATE（只发握手、不改东西）：`status=0`、`BND=127.0.0.1:10808`，
   经它发的 DNS 查询（IPv4 ATYP / 域名 ATYP 各一发）都有回包 ⇒ 代理没问题。
2. `relay.py` 的 `_open_upstream` 遇到 `proxied` 直接返回 `None` —— 配了代理就压根不开远程 UDP 上游（D58 沿用 V0.2 D099 的空白）。
3. bot 那一路：两个子代理分别追了服务端投递链和测试 / 文档面。`bot._emit` → `BotSyncStream.deliver` → `RelayServer.deliver()`，
   和真人同一段准入，没有 bot 分支；发给经代理的玩家全落 TCP 只因为服务端从没收到过他的 HELLO（`ready_for` 恒 False）。
4. 规划子代理审方案，抓到四处真问题（都进了 D71 / §108）：阻塞连代理期间路由可能被切走、关联重建后下行闸门必须清、
   `start()` 的 quiet 会吞掉失败日志、`BND=0.0.0.0` 不能换成可能是域名的 `proxy.host`。

## 改了什么（D71）

- `server/relay.py`：`_socks5_connect` 拆成 `_socks5_handshake` + `_socks5_request`（返回 BND）；新增 `_socks5_udp_associate`、
  `socks5_udp_header / wrap / unwrap`、`_Socks5UdpUpstream`（鸭子型 UDP socket + 守望控制连接）；`UdpSyncRelay` 构造参数
  `proxied` → `proxy`，`_open_proxied_upstream`（HTTP 回退、失败日志自带去重）、`_use_route` 加锁 + 开完重核对路由、
  `_on_upstream_dead`（撤上游、清 `acked` / 闸门 / 计量）、`_retry_hello`（timer 的重发分支里重建）、`_pump_remote` 认「被撤掉的 socket」。
- `server/config.py`：模板里代理那段注释改成「socks5 连 UDP 一起转、http 只转 TCP」；`test_online` 的模板一致性不受影响。
- `test/test_proxy.py`：假 SOCKS5 代理支持 `udp=True`（真中转 UDP、`bnd_zero`、`resolve`、`kill_control`、`accept_many`）；
  新增头封拆 / ASSOCIATE / `_Socks5UdpUpstream` 三组用例。
- `test/test_udpsync.py`：`_TwoServers` 改成 `make_proxy()` 钩子；`LocalServerRouteWithProxyTests` → `HttpProxyRouteTests`；
  新增 `Socks5UdpRouteTests`（IPv4 / 切路由 / 撤关联重建 / 另一路由的死不影响这一路）、域名目标、拒绝 UDP、`BND=0`、
  `ProxiedBotDownlinkTests`（假 bot → `RelayServer.deliver` → 真 `UdpSyncServer` → 假代理 → 中继注入）。

## 结果

- 两套运行时：`test_proxy test_udpsync` 133 项（+27）连跑 3 + 2 次全绿；全量 4580 / 4580 绿。
- 真代理冒烟：`_Socks5UdpUpstream` 经 10808 发 DNS 到 `1.1.1.1:53`，应答拆头回来 ✅。
  发往内网 / 环回的 UDP 经这个代理没有回包（它把一切送到远端出口，§108）—— 云服那一半冒烟做不了，留给实机 V125 / V126。
- 没提交；版本号没动。`config/server.config`（用户的文件、打包会拷进去）30~32 行旧注释没替用户改。

## 遗留

- V125 / V126 实机；发版时客户端包要重打（`relay.py` 在客户端包里），服务端包这一轮没变。
- 已知局限（§108 末条）：代理面向服务端那一侧换 UDP 源口时服务端认不出来、UDP 静悄悄停 —— 要改 `udpsync.py` 才能识别，没做。
