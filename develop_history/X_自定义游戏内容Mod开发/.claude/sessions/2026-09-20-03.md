# 2026-09-20 · 会话 18 —— X8：自定义武器开放「追踪」参数

**用户需求**：「有的武器（如卡希尔 3 号武器）是有追踪效果的，我希望追踪相关的参数也要可以自己设置
（任意自定义武器都可以设置追踪）」。

## 查明了什么（→ §50）

先派了三个 Explore 子代理并行扫（12 格链路 / `weapon.ini` 的 Homing 键 / 记录偏移逆向），
关键结论**自己拿 `re_bs.py` 复核到字节**：

- 开关就是 `HomingAngle != 0`（`0x47e35a: 83 78 78 00` + `je` 到函数尾），**没有独立开关键**；
  ini 里那个 `Homing=` 落 `+0x1c` bool，全镜像**无读点** —— 死键。
- `HomingAngle` `+0x78` **i32**、`HomingRange` `+0x7c` **f32**。★ 两个子代理在这儿**给了相反的答案**，
  是自己反汇编 `0x489400`~`0x489455` 落的锤：两个键都走整数取值器，但 Range 读完
  `fild`→`fstp dword [edi+0x7c]` 转成了 float。**光看 ini 分不出来**（两个值都写整数）。
- **追踪不挑弹体类**：`Projectile::Homing` 全镜像只有一个调用者，在 `BulletObj::Tick` 里无条件 call；
  `AppleGrenade::Tick` / `FlamingBottle::Tick` 头几条就 `call 0x47de6a` ⇒ 18 把全都能追。
- ★ **`HomingRange = 0` 是静默坑**：它同时是选靶方框的四条边，为 0 时框退化成一个点，
  永远锁不上、`[弹体+0x328]` 写 −2 后永久不再搜索 ⇒「只填转向」什么都不会发生。
- ★ 顺带发现 **18 把里已经有 2 把在追踪**（卡希尔 3 号槽的 C/P，母本逐键抄来的 30/220）。

## 做了什么

- `weaponcfg.FIELDS` 末尾两格 + `LEGACY_LIMITS` / `FIELD_GROUPS`；`WIRE_FORMAT` 2→3。
  `bshook.c`：`WTAB_FORMAT` 3 / `WTAB_FIELDS` 14 / `WTAB_FIELD[]` 加两行。记录 108 → 124 B、载荷 2241 B。
  ★ `weapondata` 本来就在抽 `homing_*` ⇒ **`bot_weapons.json` 不用重生成**。
- **`ZERO_MEANS`**（用户第 2 条要求「0 代表关掉的项目都要提示」）：只写逐指令核实过的五格 ——
  溅射两格（`0x47e75f`/`0x47e765`）、重力（`0x4921ce`）、追踪转向（`0x47e35a`）、
  ⚠ `max_velocity`（`0x47ded6` 每 tick 无条件夹、缺省 150 ⇒ 填 0 是**子弹不动**，不是「不限速」）。
  **没核实到读点的就不写**，别把推测当事实。
- **跨格判据** `homing_error()`：转向 > 0 就必须有距离，落在**有效值**（覆盖 ∪ 参考）上
  —— 卡希尔那两把参考值自带 220，只填转向是合法的。前后台同源，话只有服务端那一份。
- **提示框**：开了追踪才画「追踪 N」；**排不下才让「飞行速度」让位**（预算 =
  5 行 − 已占行数，再 × 2 项/行，算出来的）。管理页 `mode_lines()` **不截断**（用户要看完整），
  预览那块照旧是游戏里真实的样子。
- 前端只改了两处：`.hint` 那一行灰字（和错误话同位置、错误优先）、以及
  **整窗重画**（`WEAPON_PAINTERS`）—— 跨格判据意味着改一格要让另一格跟着变，只重画自己会漏。

## 在真页面上量出来的一条（差点栽）

跨格判据那句话第一版写成「填了追踪转向就要填追踪距离 —— 距离是 0 时一个目标也锁不上」，
**测试全绿、截图上也像是对的**，但在浏览器里量：墨宽 **319 px**，而那一格
（`.err`，第 3 列到行尾，1280 宽下）只有 **192 px** —— 直接溢出「对战模式」那张卡片的右边框。
`.err` 是 `white-space: nowrap; overflow: visible`（有意的，折行会把格子撑高顶歪同一行别人），
所以**写长了不报错、只会跑到卡片外面去**。改成「追踪距离要 > 0，否则锁不上目标」= 165 px。
⇒ `test_weaponcfg` 里按 **17 个汉字**兜底，注释写清这个数是量出来的、改文案要先量。
