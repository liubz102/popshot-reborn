## 查的过程（结论在 §95 / §96）

- 格挡：先把 §92 那句「`0x50a0ea` 看开关 XOR 3 格计时器」逐指令核了一遍，再往下追：
  计时器的钟是 `[Stage+0xd4]` 逻辑帧号；`SetGuard 0x502dae` 没在跑才起计时器；本人那台 `0x4958eb` 的发包条件；
  体力打破只在本人那台（`IsMine`）；不发包就清开关的三处（`Die` / 内层 `0x0016` / Init）；
  `vft+0x124` 按虚表逐类查（19 个弹体类 + Dash / Jab 真，Splash / Swing / Laser / Flame 假）；
  收方格挡那一支 `jmp 0x4ff998` 跳过正常击退。顺带订正 §92：`[+0x2d4]` 还有 `0x0017` 处理器写（`0x4fa881` 那处是 `BreakableObj`）。
- `0x0016` 原来没名字：收方 `0x50a674` 造的是 `NewMutuSkill` ⇒ 是出一招近身格斗招式。
- 匣数：`0x509feb` 唯一调用点 `0x5173e6` → `0x517383(…, 1)` 只来自 `MyCharacter vft+0x13c`（`0x514750`），
  由 `rpFire` 处理 `0x4923a5` 在弹体全造完后调、只对 `Type` 0 / 3；`0x48bac2` 在捡来的枪那种状态恒返回 1。
  用一个小脚本把 `weapon.ini` 的键对到记录偏移（`+0x21c` = `ExcludeStatusItemMagazine`，全表只有 `[ch110-03a]`；
  `MagazineCount` 缺省 1）。`OneMagazine` 死代码再核一次：`0x508de6` 第一参是 CharAttr。
