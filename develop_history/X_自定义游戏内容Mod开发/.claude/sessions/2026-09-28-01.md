# 会话 52 · 2026-09-28 凌晨 · 敌方 bot 在最下层左右晃悠、不坐弹跳台上来（Megatron01）

## 起因

用户：「刚才试玩了几局，最后一局用的空间站地图，到后面我方队友 bot 都死了，只剩我站在地图中间那层，敌方 3 个 bot 都在最下层，
正常情况下 bot 应该主动利用弹跳点跳到上面来找我，但是敌方 3 个 bot 都只会在最下层左右晃悠，不会跳上来。bot 的路径计算是不是有问题，请帮我调查原因并修复。」

## 查了什么（§135）

- `server.out` 那一局：23:19:18 `Megatron01`（载 `Megatron01_ch`，4 个台子）生存 + 道具，真人座位 0 + bot 2/4 对 bot 1/3/5；23:20:22 他那队只剩他。
  敌方三个 bot 在最下层「朝目标走」方向 ±1 来回翻；23:20:32.493 bot 3 在右下台子上 (1524,1773) 掉头往左。23:20:28 他放烟雾弹 8 秒（那段 bot 去出生点，D67）。
- 离线可达图（scratchpad `meg_repro.py` / `meg_plan.py`）：三种体型都有最下层两个台子 → 中层的台子边；A* 从 bot 那几个位置到他脚下一步就给出坐右下台子的路线。
  ⇒ 图没问题，问题在执行。`pad_usage.py`：随机 300 条路线 156 条坐台子；`pad_spurious.py`：大部分「台子边」是假的（站着往下掉几像素），Forest00 也有 150 条。
- 离线房间逐帧（`meg_scene.py`：`TerrainMixin + BotFireRoom` 挂真图、真人心跳站 / 来回走、bot 从最下层起步）一层层剥：
  1. bot 走到台子起点 → 路线下一步「站台」回 (0,…) → `_unstall` 当卡住横着探一步并闩住 → 一路走到最左边（原样复现用户看到的）。
  2. 修掉 1 之后他站着不动时都能上来；他在中层来回走时 5 个起点 3 个上不去：单子在算那一格兜底「目标在上面就跳」→ 落地时单子起点挪远被扔 → 再跳，路线永远装不上。
  3. 修掉 2 之后又看到：台子刚弹起来那格改「打得到·就地打」清了路线，下一格腾空兜底按「朝目标」拽歪弹道撞中层平台边、掉回最下层；
     他一挪路线就整条作废，等新路线那格兜底朝他的 x 走（常常是反方向，中层边上还会走下去）。
  4. `pad_reach.py`：「走到了」±8 px 里约 1/4 的台子起点有一段踩不中台子 —— 修掉 1 以后会变成站着干等。
- 试过「单子在算那一格站住等」：离线更快（73 → 30 拍），但全量 8 条红 —— 目标真到不了时每探一步就重递单、站一格，走一步停一步（D137）。撤掉。
  同一轮也把「路线一律放行解闩」收窄成 `_route_leads_there`（站台 / 到得了）：A* 只给「走到最近处」时会把探路拽回去原地抽。

## 做了什么（D95）

- `server/bot.py`：`_route_leads_there`（`_unstall` / `_blind_walk` 放行 + 解闩）、`_plan_pending`（`_walk_to` 单子在算时不凭目标在上面起跳）、
  `_pad_lean` + `_live_shape`（台子那一步踩偏了朝台子中心挪，按真跑物理的形状 / 蹲姿问 `jump_pad_launch`）、`_route_intent` 目标挪了先照旧路线走（`retarget`）、
  `BotConn.nav_air_dir`（`_own_step` 离地时记、踩地清；`_walk_to` 腾空兜底照它按）。`server/botnav.py`：`_pad_edge` 判 `current.pad`。
- 测试 +11：`test_botnav.JumpPadRouteTests` 1 条（假台子边）；`test_botsync.BotJumpPadRouteTests` 10 条（合成图坐台子端到端、站台不算卡住、踩偏挪一步、
  台子弹起没路线也按 0 飞、路线跳半空被清照原方向、单子在算不跳、目标挪了照旧路线、到得了的路线解闩 / 到不了的不解、真图 Megatron01_ch 端到端）。
  scratchpad `mutate52.py` 8 处改坏全抓到（主修复改回去两条端到端都红）。
- 两套全量 4926 绿（3.14 skip 12 / 3.8 skip 4，和上一轮一样）。
- 离线结果：他站中层不动 1.5~3 秒上来；在中层来回走 13~73 拍全上来；他在顶层（连坐两台）5~12 秒；修之前前两种一次都没上来。
