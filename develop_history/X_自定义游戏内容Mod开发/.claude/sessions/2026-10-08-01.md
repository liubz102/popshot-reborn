# 2026-10-08 会话 66 —— X22 全屏画面「保持比例 / 拉伸」进游戏设定界面 + 版本升 0.5.2（§150 / D108）

## 用户说的

1. 「之前改无边框全屏时固定两边加了黑边……有玩家更喜欢拉伸填满。加一个配置选项，让每个人自己设置保持原比例还是拉伸。另外 4:3 显示器能否正常填满？」
2. 看了「`config/server.config` 加键 + 启动脚本传环境变量」的方案后：「能不能通过 hook 在画面加一个下拉框，从游戏界面内部设置？可以的话就存在 UserConfig.ini 里，原版是否全屏也存在这里，两个选项放一起。」默认值选「保持 4:3」。
3. 看了下拉框方案后：「反正设置界面都要加高，那就把原来分辨率选择的几个选项里『全屏』分成两个：全屏(保持比例) / 全屏(拉伸)」；「版本帮我改成 0.5.2」；`server-ClientFilter.config` 也一起改 0.5.2。

## 4:3 显示器的答案

`fsv_fit` 在显示器里放最大的 4:3 矩形 ⇒ 4:3 屏上画面就是整块屏，两种全屏完全一样；5:4（1280×1024）保持比例上下各 32 像素黑边。夹具补了 1280×960 / 1400×1050 / 1600×1200 / 1152×864 并钉「4:3 屏两种模式相同」。

## 查的过程（结论在 §150）

`Option2.ui` 是数据（UTF-16LE XML），加载器按标签通用建控件、初始化 `0x41de2f` 按名字（`vf[0x18]`）取三个模式按钮配样式绑点击、末尾回填；三个按钮都转单选 `0x41ee98`；
模态 ==2 才调应用 `0x41eff5`（SetFullScreen = 切模式 + 存键）。UserConfig 是通用键值表，退出 / 登录整表写回 ⇒ 直接写 ini 没用，要经游戏的 SetInt（`0x411ebe`，esi=cfg）/ GetInt（`0x410110`，ebx=缺省）。
下拉框也查了（`UiComboBox` 加项 / 设选中 / `[cb+0x5f8]`），用户改成拆单选后没用上。
