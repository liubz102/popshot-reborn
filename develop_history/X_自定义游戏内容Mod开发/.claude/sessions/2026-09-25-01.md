# 2026-09-25 会话 38 —— 「幸运幸存者的 50% 免伤是不是太破坏平衡」

## 用户说的

「幸运幸存者这个称号的效果，说明里写的是 50% 的概率伤害无效，如果真是这样，这个效果好像有点太破坏平衡了。
帮我再查一下，这个伤害无效的触发还有没有什么条件，有效期或其他方面上有没有什么限制。」

## 查的过程

1. 旧结论 V0.3商店 §53⑤ 只记了 `0x480995` 掷 0.5f → `0x4809b4` 清零两句；说明文 `shopcfg.SPECIAL_EFFECT_BY_ID[560004]`
   照它写成「受到伤害时 50% 概率完全免疫」。
2. 把伤害函数 `0x4806bf` 整个反汇编一遍：掷点前面还有 `vft+0x48 == 0x190`（是角色）、`vft+0xac < 15`、`vft+0xac < 伤害`
   三道门；`Character` 虚表 `0x6846fc` 核实 `+0x48` = `mov eax,0x190`、`+0xac` = `[+0x150]` 当前 HP。
3. `0x88b84` 全镜像搜 4 字节立即数：只有 `0x4809aa` 一处 ⇒ 无状态、无次数、无时限。
4. 谁会走到它：`vftables.json` 里 `+0x128` 槽逐个对 —— `DamagingObj` 基类就是 `0x4806bf`（溅射、火墙等 10 个子类继承），
   19 个弹体类 `0x47e618`、`DashDamage` `0x481dfd` 都先调它。
5. 扣血点 `0x50f784` 是 `HP ≤ 0` 就死 ⇒ 「HP == 伤害」时门不开、人照死。
6. 掉出下边界走 `ProcessFallDown → ReportDeath`（V0.3bot §143），不经伤害函数。
7. 服务端 `server/*.py` 搜 `560004` / `0x88b84` / `LUCKY`：只有说明文和配方，没有判定；`bot._damage_scale` 的注释也写明
   受害者装备那一串服务端不碰 ⇒ 对战里 bot 打真人永远不触发。
8. `ChrProps.ini`：角色 0 / 1 / 2 / 3 满血 100 / 90 / 130 / 90。

FINDINGS §90；packet_api §5.3 的 `0x100` 那一行补了触发条件。报给用户两件待定：说明文、bot 打人的受害者一侧。
