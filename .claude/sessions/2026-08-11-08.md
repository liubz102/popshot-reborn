# V0.2 会话 08 —— J.3 的战斗逻辑（2026-08-11）

用户一句话：「开发剩下的战斗逻辑」。

## 做了什么

### 1. 先做 RE（PROGRESS 上一版的硬要求）

上一版 PROGRESS 写着：「★ **动手前先做 RE**：现有实现全是『原样回显给发包的
那一个人』，改成广播之前要先确认客户端**对别人的座位**也认这些包 ……
**别照着「应该能行」直接改**」。

照做了，结论写进 **FINDINGS §161**。最关键的一条：

> **玩家角色的对象句柄 = 座位 × 100000 + 100001**（`0x405f02` 的
> `imul ecx, ebx, 0x186a0 / add ecx, 0x186a1`），六台机器上算出来一模一样。

这一条一确定，「死亡广播给别人有没有意义」就不再是猜的了。逐个包核对下来
六个包全部可以广播，且**找不到目标时一律整包丢掉，不会崩**
（`0x493914` / `0x551d7c` 都有 `test/je`）。

顺带查明的：

- `0x0405` 拾取放行有**两把钥匙**（座位 → 角色、句柄 → 物件），所以广播是对的；
- 客户端**只在事件属于自己时才上报**（`0x508cbb` / `0x4faa94` / `0x4fe70e`
  三处都有「是不是我的座位」判据），唯一会重复上报的是**怪物的死亡**；
- 结算尾部数组有**三个档**：`1` 完成+胜利曲 / `0` 未完成+**胜利曲**
  （`setge` 是 `>= 0`）/ `-1` 未完成+失败曲。0 和 -1 不能合并；
- `0x0411` 每发一份客户端就回一发 `0x0505` 遥测（`0x4087f0`）；
- `0x0311` 那六项是**六个座位**不是六种游戏类型（旧注释已勘误）。

### 2. 实现

`lobby.Room` 加空槽 `quest`；`gameserver` 新增 `RoomQuest`（房间级的一局）
和三个取数口（`quest_state` / `battle_members` / `battle_seats`），
**战斗处理器只有一条代码路径**（D084）—— 不在房间里时退化成 V0.1 的单连接回显。

改了八个包：`0x0408→0x0406`、`0x0413→0x0419`、`0x0406→0x0404`、
`0x0407→0x0405`、`0x0410→0x0415`、`0x0411→0x0417`、`0x0412→0x0418`、
`0x040f→0x0309+0x0411`，外加 `0x0417 gcpMarkQuestSuccess` 记在房间上。

三件服务端仲裁：**一件东西只能被一个人捡到**、**同一次死亡只广播一次**、
**一局只结算一次**。

顺手补的两个坑（都是多人才会暴露的）：

- `current_quest()` 只看 `self.room`，而那是**房主**解析 `0x0201` 得到的
  —— 客人打通关卡难度解锁不了。改成先读大厅那一份。
- 结算完回房间没有复位 `room.battle`，它停在 `IN_GAME`，
  **房主再按一次「开始」第二局根本开不起来**。

### 3. 验证

- `server/run_tests.py` **467 项全过**（新增 `test_battle.py` 41 项）。
- **两个假客户端 + 真服务端跑完整的一局**（§162），全部是真 TCP + 真票据：
  广播 / 仲裁 / 换图等人 / 每座位一份结算 / 只结算一次 / 各按各的分入账 /
  客人也解锁难度 / 房间状态 / 第二局能开 —— 全过。
  为此给 `tools/fakeclient.py` 加了整套战斗命令。

## 决策

D082（`0x0309` 每座位一份、`0x0411` 每人一份）、D083（对战按分数判胜负）、
D084（战斗处理器只有一条路径）、D085（死亡次数照旧用「报的值 +1」）。

D082 有个**明说的代价**：结算界面上队友那一行的「分数 / 生命」会是 `0 / 3`
（那一格只有 `0x0411` 会写）。改成每座位一份 `0x0411` 就好了，
但重复调 `0x4087f0` 安不安全没有 RE 依据，保真项目里不主动踩没读到底的分支。

## 中途踩到的两件事

1. 死亡去重一开始只用**句柄**当键 —— 老测试
   `test_death_broadcast_increments_the_death_count` 当场变红：
   同一个角色会死很多次，第二次就被吃掉了。改成
   **`(句柄, 客户端报的死亡次数)`** 才对（重复上报的两发一定同值，
   真的第二次死一定更大）。
2. 房间状态一开始在**倒计时刚开始**就切「游戏中」——
   把「新人进房 → 上一轮握手作废」那条路废了（新人根本进不来）。
   改成**所有人都加载完、真进 stage 7** 才切。

两条都是老测试逼出来的，不是想出来的。
