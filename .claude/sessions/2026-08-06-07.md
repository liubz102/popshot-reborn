## 做了什么 / 结果

### 1. D3D9 卡点解除（§61、D030）

退出串流后**不做任何其它改动**重跑 `tools/d3d9_probe.exe`，
32/64 位 × HAL/REF/9On12/WARP **全部** `hr=00000000`。
`XMD009A` 虚拟显示目标依旧 active/attached，GameViewer/Meta 适配器依旧被枚举到 ——
所以会话 06 §60 猜的「静态拓扑」不对，真正的开关是**串流软件是否在跑**。
D027 里「必要时手动禁用虚拟显示设备」这一步实测**不需要**。

### 2. 新手教程跳过实机验收通过

登录 → 大厅只弹「活动」公告，**新手向导彻底不出现**。

截图 `2026-08-06-07-lobby.png`（含公告窗）、`2026-08-06-07-lobby-clean.png`（关掉之后）。

### 3. 「任务」标签页切换打通（§62、D028）

点标签一开始「没反应」。日志里发现客户端发了 `0x020b gcpReqMoveChannelByGameType`
（载荷 `02 00 00 00` = 游戏类型 2），我们没回应答。

逆向发现同号的服务端 `0x020b` **两条分支都是失败提示**（韩文原版
「移动到能玩该游戏的频道失败」），成功应答其实是
**`0x0701 gspRepMoveInto {int32 ok, int32 channel_code, int32 channel_index}`**。
频道码↔游戏类型映射抄自 `0x5545ec`：`0~4/6/10→普通`、`7→闯关`、`9→天梯`。

顺带查清：**等级 6 的门槛只卡「天梯」标签，不卡「任务」**（`0x43b676`）。

实现进 `server/gameserver.py` 后，标签页正常切换，标题变成「任务 = 任务 0 频道」，
底部按钮从「开始射击」变成「快速开始」。截图 `2026-08-06-07-quest-tab.png`。

### 4. 闯关关卡列表解锁（§63、D029）

「建立房间」对话框能开，但「任务」下拉框空着。
先用新工具 `tools/probe_quest_list.py` 读活进程里的关卡目录（`[0x72e3d8]` 红黑树），
确认**记录是在的**（id 1/2/3/4，掩码也通过）——排除了「要服务端下发解锁列表」的思路。

真凶在对话框初始化 `0x436833`：`mov ebx, [0x72e338]` = **玩家等级**，
四个下拉框全按「等级 >= 条目要求等级」过滤。三张静态表要求等级 0（所以正常填充），
关卡记录要求等级 1，而我们登录包一直发 0 → 每个关卡都被跳过。

`gspRepLogin` 第 1 个业务 int32 接上账号 `level` 后，下拉框正常出「神秘岛」，
左上角变成 Lv.1。截图 `2026-08-06-07-quest-dialog.png`。

### 5. 建闯关房 → 崩溃 → 根因查清（§64、§65）

点「确认」，服务端收到并解出：
`type=2 (quest)`、`texts=('想和做朋友吗?', 'Quest03_1', '')`、`option=3`、`args=(3, 1)`
= (关卡 id 3, 难度 1)。§59 的解析器逐字段解对。

回了 `gspRepCreateSession {0, 1}` 之后客户端进房，~5 秒崩溃退出。
**客户端自带崩溃报告** `game_patched/Dump/LastCrashReport.txt`，
给出 `C0000005 @ 0x40197F` + 寄存器 + 完整调用栈。

顺栈查明：崩在 `DlgSelectPvpMap` 用房间描述符取「模式名」。
三个访问器（`0x409dd9/0x409df1/0x409e0a`）对 type≠1/5 一律返回 **-1**，
查表 `push [eax*4 + 表基址]` 不做范围检查，前两张表的 -1 项恰好是有效字符串（侥幸不崩），
第三张表的 -1 项是空指针 → `TString(NULL)` → 崩。

再用新工具 `tools/probe_session_desc.py` 在建房窗口里连续采样 `LobbyStage`：
`session_id` 从 0 变 1（说明我们的应答生效）、`me==host==0`（房主判定正常）、
但 **`descriptor.type` 全程是 -1**。`LobbyStage` 构造函数 `0x4052ff` 就把它初始化成 -1，
**客户端自己永远不会填成 2，必须服务端下发。**

最后定位到下发它的包：大厅分发器跳表 `@0x406332` 索引 3 = **opcode `0x0303`**
→ `0x406756` → `0x556ed1`，把整个 Session（含 SessionDescriptor）反序列化进 `LobbyStage`。
完整线格式和原语宽度表记在 §65。
