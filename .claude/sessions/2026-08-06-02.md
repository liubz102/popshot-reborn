## 做了什么（一条主线，一次通关）

### 2. 动态 hook 反推 GameGuard 校验点（关键手法）
静态爬那坨混淆的 nProtect 代码太慢，改动态：
- 给 `bshook.dll` 加了**极简 x86 长度反汇编器** `insn_len` + **通用内联 hook**
  `install_inline_hook`（偷≥5字节做蹦床）+ **EBP 链回溯** `log_ebp_chain`。
- 内联 hook `user32!MessageBoxW`/`MessageBoxA`（Win10 序言正好是热补丁 5 字节
  `8b ff 55 8b ec`，干净可偷）。错误框弹出时抓 `_ReturnAddress` + EBP 链。

一次运行拿到铁证：
```
MessageBoxW(hwnd,"Game guard启动过程中发生错误…","公告",MB_OK)
调用点 0x40f4bf (call [0x6e6290]=游戏IAT的MessageBoxW)，返回 0x40f4c5
EBP链: 0x5f7b9e → 0x40a68e(vtable虚调用) → 0x40d039 → 0x54b042 → 弹框封装
```

用 `re_bs.py` 静态确认判定链：
```
0x40d034: call 0x54b042      ; GameGuard 校验，返回 al
0x40d039: test al,al / je 0x40d545   ; al==0 → 失败退出
—— 0x54b042 内部：
0x54b0fc: call 0x5611d0      ; 取 GameGuard 状态(读 [[0x6e6624]+0x10] + 打日志)
0x54b103: cmp esi,0x755 / je 0x54b572  ; 0x755=成功码；否则弹框返回0
```

### 3. 打 patch（5 字节等长）
`bshook.dll` 加 patch 线程，等 0x54b0fc 解壳出 `E8 CF 60 01 00` 后写
`B8 55 07 00 00`（`call 0x5611d0` → `mov eax,0x755`）。

### 4. 实测通关
- patch 在 +0.007s 生效，**全程无 MessageBox / 无「公告」错误框**。
- 客户端跑到 **「PopShot」登录界面**：选择分区(炮火连天电信/枪林弹雨网通)、
  用户名/密码、记住帐号、开始按钮全在。截图 `2026-08-06-02-login.png`。
- 进程稳定存活 >22s（此前 ~5.6s 必退）。**阶段 2 验收达成。**
