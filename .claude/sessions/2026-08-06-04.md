# 会话 04 — 2026-08-06

## 起点

接会话 03：登录包已能完整解码（两层异或 + 反解出的 64 字节固定流 F），
但**服务端 → 客户端方向零样本**，F 的生成算法也没找到。
交接建议是「先随便回一包看客户端反应」，必要时 hook `ws2_32!recv` 拿回溯。

## 做了什么

### 1. 先按原计划从 RTTI 反查 opcode（走了一半发现方向不对）

写了 `tools/rtti_map.py`，把脱壳镜像里 120 个 `Packet_gcp*`/`gsp*` 的
TD → COL → vftable 全列出来了（这个工具本身有用，留给里程碑 B）。
但**列表里没有普通登录包**，只有 `gcpReqDbgLogin` / `gcpReqJpnLogin`
—— 说明 47611 认证服根本不走 gcp/gsp 体系。

### 2. ★★★ 一次搜索改变了整个会话：F 表在未加壳的 DLL 里

拿会话 03 反解出的 F 前 8 字节去搜所有模块，**在 `nmconew.dll` 和 `NMService.exe` 里命中**，
展开一看 **64/64 逐字节精确匹配**，是一张硬编码常量表。

再查 bshook 日志确认：客户端点「开始」connect 的同一刻
**`nmconew.dll` 被动态加载进 BigShot 进程**。

→ **登录协议根本不是游戏自己的，是 Nexon 通行证 NMCO，而那套代码没加壳。**
会话 03 辛苦差分反解的东西，在磁盘上本来就是明文可读的。

### 3. 写 `tools/re_pe.py`，把整个传输层静态读出来

`re_bs.py` 只能处理那份 file offset == RVA 的平坦转储，磁盘上的正常 PE 得另写。
然后顺着 F 表的两个引用点一路读完：

- `0x1009f270` 加密 / `0x1009f2f0` 解密：`C[i] = P[i] ^ P[i-1] ^ key ^ Fw[i&15]`
  （**明文反馈**；我一开始把加解密方向读反了，回头重读汇编才纠正）
- `0x1008cbb0` 组 16 字节头 / `0x1008c180` 解 12 字节头 / `0x1008bdb0` 校验 `0x18` tag
- `0x100981d0` 最外层写 `[u16 BE 长度][u16 BE opcode]`

**用静态读出的结构去解真实抓包，逐字节复现，重新加密后与原密文相同。**
这与会话 03 的差分结果互为独立验证。

### 4. ★★★ 还原完整 opcode 表

基类构造 `CNMFunc::CNMFunc(int opcode)`（`0x100980f0`）把 opcode 写进 `this+0x10`；
派生构造形状固定。写 `tools/nmco_opcodes.py` 枚举 30 个派生构造 → 16 个 opcode。

类名靠 `.data` 里 16 个工厂类型描述符（`.P6APAVCU<类名>Packet@@XZ`）对上：
它们的排列顺序与「按构造地址排序的 opcode」一一对应，
7 组 Request/Reply 全部落成相邻 `n / n+1`，两个没有 Reply 的类正好落在两个落单 opcode 上。
**自洽得没有别的解释。**

关键结论：客户端发的 0x0f 是 `CULogin2Packet`，应答是 **0x0c `CULoginReplyPacket`**。

### 5. ★★★ 假认证服跑通，客户端走完整个握手

`server/authserver.py`，字段按各包 `Deserialize` 的读取顺序**全填 0**：

```
0x0f → 0x0c   客户端接受，关连接，另开一条
0x2d → 0x2e   客户端接受，再开一条
0x0d → 0x0e   客户端接受
然后 connect 222.73.209.12:27799
```

客户端依次发来的 0x0f / 0x2d / 0x0d **全在推导出的表里** —— 三次独立验证。

### 6. 抓到下一跳首包

扩 `authserver.py` 支持多端口，抓到 27799 的首包：**4 字节 `53 72 8f 7f`**，
没有 NMCO 的 tag，4 字节正好是 SnowCipher 的块大小 → 游戏自有协议那套。

### 7. 中间走过的弯路（都记进死路清单了）

- 在 `BigShot.exe` 转储里找登录代码：白费，代码不在主模块
- 登录后重新转储指望 `.data` 解开：熵值一点没变，ASProtect 页级保护用完会重新加密
- 从 `CNMLoginAuthFunc` 找线上格式：走偏，`CNM*Func` 是本地 IPC 层不是线上包
- 扫静态分发表：没有，注册是运行时建 map
