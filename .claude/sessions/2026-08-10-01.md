## 关键发现（详见 FINDINGS §122）

`re/packets.txt` + `re/rtti_types.txt` 里有 `gcpStartTcpRelay` / `gspJoinRelay` /
`RelayConnection` / `RelayAuthData` / `UDPBinder` / `UdpPacket` /
`gspToggleUdpClientCommunication` / `rcpRegister`，而 V0.1 一直没找到「角色位置同步包」。
两条合起来指向：**战斗内同步根本不在 gcp/gsp 协议里，走的是客户端之间的 UDP 直连 +
TCP 中继兜底**。`gcpReqLogin` 上报客户端**内网 IP** 这件事（V0.1 §44）是佐证。

这决定了云端联机能不能打，是 V0.2 唯一有真实失败风险的一段 → 拆成 J.1 探查 / J.2 问用户 / J.3 实现。
