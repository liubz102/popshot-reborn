# 会话 03 — 2026-08-06

## 做了什么

### 1. 从 RTTI 一路挖到 SnowCipher 的全部实现（静态）

`.?AVSnowCipher@@` → TD 0x6e6028 → COL 0x6a47c0 → vftable 0x692f28（4 个虚函数）。
反汇编虚表得到关键事实：**加密是 32 位加法，不是异或**；块大小 4；
密钥流由 0x5dbf85 一次生成 16 个字。

再顺着 `0x5dbf85`（603 条指令、16 轮全展开）和 `0x5dc7bc`（762 条、32 轮初始化）读完，
确认就是**标准 SNOW 2.0**：常量表 `T0[1]=0xe19fcf13` / `T1[1]=0x180f40cd` 正是参考实现的值，
S 盒是 AES T-table 的 4 个旋转。写出 `server/snow.py`（表直接从转储里抠，不重新推导）。

顺带发现原版把 key 声明成了 `char*` —— loadkey 里编译出的是 `movsx`，
key 字节 ≥0x80 时和普通大端取字不等价。这个 bug 必须照抄。

### 2. 离线爆破失败（花了不少时间，但排除了一大片）

枚举镜像里全部 37596 个字符串当密钥源去解登录包 —— 全不中。
针对性试 "222.73.1.42" 等也不中。

### 3. 动态 hook：拿到密钥，也拿到了标准答案

给 `bshook.dll` 加了 `SnowCipher::loadkey/Encrypt/Decrypt` 三个内联 hook（naked detour）。
第一次跑就抓到密钥 `Pben3Ig{i9:;<;~z`，**逐字节减下标 → "Pack/Data0000.pk"**。

→ **`Pack\*.pkn` 和 `BigShotCN.ini` 的密钥就是文件名本身**，
`key[j] = 名字[j%len] + j`（派生函数 0x5608b0）。
FINDINGS §4 里那个「文件名为什么是明文」的疑问，答案是：它就是密钥。

后来把 `Snow::Decrypt` 改成完整包装（调原函数后再记输出），抓到 7 个字的
（密文, 明文）配对，**`server/snow.py` 与客户端逐位一致**。算法这块彻底钉死。

### 4. ★ 撞上 ASProtect 的完整性校验，顺手修了一个一直存在的间歇 bug

加了 SnowCipher hook 之后开始间歇性弹「Protection Error / Error: 15」卡死。
排查：
- 不注入直接跑 → 不报，确认是我们的 patch 触发的。
- EBP 回溯 → 调用链全在 ASProtect 动态代码区，最外层 `ret=0` = **它自己的线程**。
- 控制实验：**只有 GameGuard patch 时，连跑 4 次也有 3 次被抓**（成功率 ~25%）。
  也就是说会话 01/02 一直在赌运气，只是没注意到。
- 把 patch 从 +0.7s 延后到 **+2.5s**（校验点 +5s 才执行）→ **连跑 5 次全过**。

### 5. ★★ 解开登录包外层：一次一密的 4 字节 XOR，密钥就在包里

hook 全装上之后完整跑登录，5 个 cipher 函数**一次都没被调用**；
静态搜表引用也证明没有内联副本 → **登录包不是这两种 cipher 加的**。

改用差分：拿同一账号、两次不同运行的 70 字节包做 XOR，
得到严格周期 4 的 `61 91 f4 03`（off 20..67），而 off 12..15 的差分正是它的逆序。
→ off 12..15 是**明文传输的会话密钥**，body 从 off 20 起按逆序循环异或。

验证：两次不同运行解出的 48 字节体**完全相同**。帧格式全部定死（FINDINGS §31）。

### 6. ★★★ 再剥一层，登录包彻底解开

剥掉一次一密后还剩一层固定变换。用「明文结构假设」做差分校验一次命中：
`out差[i] == 明文差[i] ^ 明文差[i-4]`，12/12 全中 → 结构是
`[u16 用户名长][UTF-16 用户名][u16 密码长][UTF-16 密码][12 字节尾]`，
变换是 `out[i] = plain[i] ^ plain[i-4] ^ F[i]`（4 字节明文反馈 + 固定密钥流 F）。

用已知明文反解出 F，再跑一次 16+16 长账号的登录把 F 延长到 68 字节 ——
发现 **F[64..67] == F[0..3]，周期正好 64**。至此算法闭合。

4 个样本（testuser 两次、abc/z、长账号）全部解出正确凭据，12 字节尾部完全一致。
写成 `server/protocol.py`，`pack()` 出来的字节与真实抓包**逐字节相同**。
