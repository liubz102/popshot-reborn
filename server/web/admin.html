    数据备份

    • 备份的是 server/data/ 下的全部 json （物品库 / 商店货架 / 合成配方 / 材料掉落 / 金币经验 + 玩家存档 accounts.json，以后新加的也算），存在 server/data/backups/ 里，一份一个目录，可以直接打开看。
    • 自动备份每天到设定时刻做一次（服务器本地时间）；服务端那时没开着 就没有那一天的。保留天数对手动备份、回滚前的备份一样有效， 0 = 永不自动删除。
    • 回滚会先把现在的状态自动备份一份，再用所选的那份覆盖当前的。 运营配置那几份互相关联，只能一起回滚；玩家存档默认不回滚， 勾了会把所有玩家的进度倒回去。
