    玩家资料

    • 按用户名或昵称搜（对大小写不敏感，写一部分就行；留空列前几个）。
    • 等级改的其实是经验 —— 等级是从经验推出来的派生字段， 所以会落到该等级的起点经验。已经是这一级就不动它。
    • 仓库里什么都能加、什么都能改，商店在卖的也一样 —— 等级门槛在穿上那一刻客户端还会再判一次， 等级不够的东西塞进仓库也穿不上身。
    • 玩家在线时改完即时生效（金币 / 等级 / 仓库 / 装备一起推下去）， 不用重登。

    数据备份

    • 备份的是 server/data/ 下的全部 json （物品库 / 商店货架 / 合成配方 / 材料掉落 + 玩家存档 accounts.json，以后新加的也算），存在 server/data/backups/ 里，一份一个目录，可以直接打开看。
    • 自动备份每天到设定时刻做一次（服务器本地时间）；服务端那时没开着 就没有那一天的。保留天数对手动备份、回滚前的备份一样有效， 0 = 永不自动删除。
    • 回滚会先把现在的状态自动备份一份，再用那份覆盖。 四份运营配置互相关联，只能一起回滚；玩家存档默认不回滚， 勾了会把所有玩家的进度倒回去。
    • 这里改的设置会立刻生效并写回 config/server.config，不用重启。
    时刻 保留天数（0 = 永不自动删除）

    管理员账号

    密码是明文保存的（和玩家账号一个口径）。 至少要保留一个系统管理员 —— 全删光了（或者全降成运营） 就没人进得来这一页，只能上服务器改 JSON。

    • 系统管理员：管理页所有标签页都能进，包括「玩家资料」和这一页。
    • 运营：只能进 物品库 / 商店货架 / 合成配方 / 材料掉落 这四页，看不到「玩家资料」和「管理员账号」。
    • 改权限立刻生效，对方不用重新登录。
