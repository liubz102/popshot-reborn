运营配置

直接改 JSON。保存前服务端会校验一遍，不合格就不落盘； 存进去即刻生效，不用重启服务端。
shop.json 上架 / 定价，recipe.json 合成配方 （一条最多 4 种材料），drops.json 材料掉落。
以 _ 开头的键（比如 _说明）是给人看的注释， 校验器不管它们，保存后原样保留。

物品速查

填 itemId 看它是什么。★ 查不到的 id 不要写进配置 —— 中文版客户端不认识它，发下去界面上就是个空格子。
